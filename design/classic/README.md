# Sonar · классика

Кликабельный прототип нового вида Sonar «в духе Apple Music» — по брифу `SONAR_CLASSIC_PROMPT.md`.
Выбран **вариант A** (Manrope, плотнее и ярче), обе темы. Живое приложение (`windows/`, `ios/`) не
трогается — это песочница, из которой потом переносится вид. Передача дизайнеру и в код — **`HANDOFF.md`**.

## Как открыть

Двойной клик по `index.html` — работает прямо с диска. Или локальный сервер:

```bash
cd design/classic && python3 -m http.server 5190
```

Нужен свежий браузер (Chrome / Edge 122+, Safari 18): цвета считаются через `oklch(from …)`.
Слева — ПК 1440×900, справа — iPhone 393×852; оба живые и играют один и тот же трек.

## Что есть

**ПК:** Главная (герой Sonar Mix, полки, «Для тебя»), Sonar Mix, Любимые, плейлисты, исполнители,
альбомы, локальные файлы, страницы плейлиста / альбома / исполнителя, поиск и быстрый поиск (Ctrl+K),
статистика и итоги-«истории», карта исполнителей, полноэкранный плеер (текст с караоке, очередь),
эквалайзер, настройки с 3D-открытием (Вид · Звук · Сервисы · Профиль · Sonar Deep · Система), меню трека.

**iPhone:** вкладки Главная · Поиск · Медиатека · Профиль, стек экранов с «Назад», мини-плеер, морф
мини-плеер ⇄ полноэкранный плеер (обложка перелетает), текст и очередь в плеере, нижний лист меню трека,
настройки.

У каждого экрана три состояния: данные, загрузка (скелетоны), пусто.

## Панель сверху

| Группа | Что делает |
|---|---|
| Тема | тёмная / светлая |
| Обложка | «из трека» или один из шести цветов — проверить чёрную, кислотную, бежевую, синюю, зелёную, серую |
| Показать | оба фрейма / только ПК / только iPhone |
| Ширина | ПК 960 · 1280 · 1440 · 1920 · 2560 |
| Состояние | Данные · Загрузка · Пусто |
| Движение | Всё · Меньше (только прозрачность) |
| Сцены | заставка, мини-окно поверх окон, «Доступно обновление», тост |

## Клавиши

Пробел — пауза, ← → — треки, Esc — закрыть по очереди: меню → подсказку → оверлей → панель.
В поиске ↑ ↓ и Enter. Всплывашки открываются и закрываются **только кликом**.

## Ссылка на конкретный экран

Состояние живёт в адресе — экран можно прислать ссылкой:

```
index.html#route=artist/a2&overlay=full&theme=light&cover=%23ff2d95&width=1920&load=empty
```

| Ключ | Значения |
|---|---|
| `theme` | `dark` · `light` |
| `view` | `both` · `pc` · `phone` |
| `route` | `home` `mix` `liked` `playlists` `artists` `albums` `files` `search` `stats` `map` `playlist/<id>` `album/<id>` `artist/<id>` |
| `overlay` | `full` · `eq` · `settings` · `recap` · `quick` |
| `tab` / `sec` | вкладка полноэкранного плеера (`lyrics` · `queue`) / раздел настроек (`look` `sound` `services` `profile` `deep` `system`) |
| `load` | `normal` · `loading` · `empty` |
| `width`, `motion`, `cover`, `q` | ширина ПК, `reduced`, цвет обложки, запрос поиска |
| `ptab`, `psub` | вкладка iPhone и стек экранов через запятую (`playlist/pl0,set/look`) |
| `popen`, `ppane`, `sheet` | плеер iPhone открыт (`1`), его панель (`lyrics` · `queue`), меню трека (id трека) |

## Файлы

| Где | Что внутри |
|---|---|
| `css/tokens.css` | токены: цвет из `--cover` формулами oklch, движение, типографика, стили, шрифты |
| `css/base.css`, `css/controls.css` | общие кирпичи: обложки, кнопки, ползунки, карточки, строки треков, переключатели |
| `css/stage.css` | сцена, панель сверху, рамки устройств |
| `css/pc/*.css` | ПК: оболочка, главная, страницы, поиск, плеер, эквалайзер, настройки, статистика, карта, сцены |
| `css/ph/*.css` | iPhone: оболочка, экраны, плеер |
| `js/core.js` | регистрация модулей `S.use({ pages, overlays, actions, hash, keys })` |
| `js/main.js` | одно неизменяемое состояние, отрисовка, действия, адрес, клавиши |
| `js/player.js` | общий плеер: ход времени, очередь, лайки, скорость |
| `js/data.js`, `js/data-more.js` | придуманные треки, исполнители, плейлисты, статистика |
| `js/art.js` | 24×24 значки, генератор абстрактных обложек, лого, значки сервисов |
| `js/parts.js` | общие куски разметки |
| `js/pc/*.js` | экраны и оверлеи ПК |
| `js/ph/*.js` | iPhone: оболочка, экраны, плеер, морф |
| `icons/*.svg` | 64 значка отдельными файлами (из `js/art.js`) |
| `tools/export-icons.mjs` | выгрузка значков: `node tools/export-icons.mjs` |
