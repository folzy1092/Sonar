# Sonar · классика

Прототип нового вида Sonar «в духе Apple Music» — по брифу `SONAR_CLASSIC_PROMPT.md`.
Первый шаг брифа: **главная ПК и полноэкранный плеер iPhone в двух вариантах**, чтобы выбрать один.
Живое приложение (`windows/`, `ios/`) не трогается — это отдельная песочница.

## Как открыть

Двойной клик по `index.html` (открывается прямо с диска, сервер не нужен).
Нужен свежий браузер: Chrome / Edge 122+ или Safari 18 — цвета считаются через `oklch(from …)`.

## Что сравнивать

| | A · Плотнее и ярче | B · Больше воздуха и тише |
|---|---|---|
| Шрифт | Manrope | Onest |
| Цвет обложки | заливает героя и фон плеера сильнее | лёгкий оттенок, больше нейтрального |
| Главная | тёмный герой «Sonar Mix» с кольцами | светлее и спокойнее, крупнее отступы |
| Плеер iPhone | обложка во всю ширину, громкость, кнопка пуска в круге | обложка меньше, без громкости, кнопки голые |

Общее у обоих: обложка — главный герой, один акцент из цвета обложки, анимации 140–450 мс
без пружин, «меньше движения» — только прозрачность, название и артист выделяются.

## Панель сверху

- **Вариант** — A или B.
- **Тема** — тёмная / светлая.
- **Обложка** — «из трека» (радуга) или один из шести цветов: проверить, что вид держится
  на чёрной, кислотной, бежевой, синей, зелёной и серой обложке.
- **Показать** — оба фрейма, только ПК или только iPhone.

Клавиши: пробел — пауза, ← → — треки, Esc — свернуть плеер iPhone.
На iPhone тап по мини-плееру разворачивает плеер, ⌄ — сворачивает (обложка перелетает).

## Файлы

| Файл | Что внутри |
|---|---|
| `css/tokens.css` | токены oklch, цвет от обложки (`--cover`), оба варианта и обе темы |
| `css/base.css` | общие кирпичи: обложки, кнопки, ползунки, карточки, строки треков |
| `css/stage.css` | сцена сравнения и рамки устройств |
| `css/desktop.css`, `css/phone.css` | раскладка ПК и iPhone |
| `js/data.js` | демо-треки, настроения, плейлисты (обложки абстрактные) |
| `js/art.js` | значки (свои SVG), генератор обложек, лого, значки сервисов |
| `js/parts.js` | общие куски разметки |
| `js/desktop.js`, `js/phone.js` | экраны ПК и iPhone, морф мини-плеер ⇄ плеер |
| `js/main.js` | состояние (неизменяемое), отрисовка, действия, ход времени |
