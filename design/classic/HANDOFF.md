# Sonar · классика — передача

Что нужно, чтобы перенести вид из прототипа в `windows/` (Svelte) и `ios/` (SwiftUI) без догадок.
Источник правды — `css/tokens.css`; здесь то же самое, но с объяснением, зачем каждая формула.

## Манифест

1. **Обложка — герой.** Самый крупный и самый цветной предмет на экране — обложка трека. Интерфейс
   вокруг неё тихий: тёмно-серый или почти белый, подкрашенный её оттенком.
2. **Один цвет — из обложки.** Акцент, герой, фон плеера, кольца, полоса прогресса считаются
   из одного `--cover`. Своих «брендовых» цветов в интерфейсе нет. Исключения: красный для удаления
   и значки сервисов.
3. **Держится на любой обложке.** Светлоту задаём сами и ограничиваем насыщенность, а оттенок
   берём у обложки как есть. Чёрная, кислотная, бежевая и серая обложки дают одинаково читаемый
   экран; у серой интерфейс просто нейтральный.
4. **Движение без перелёта.** 140–450 мс, `ease-out` с мягкой посадкой, без пружин и отскоков.
   Цвет меняется дольше всего (450 мс), чтобы смена трека ощущалась как переход, а не мигание.
5. **«Меньше движения» — только прозрачность.** Никаких сдвигов, масштаба и размытия. Фоновые
   циклы (кольца, эквалайзер, дрейф фона) останавливаются.
6. **Всплывашки — только кликом.** Меню, листы и подсказки открываются и закрываются по клику,
   а не по наведению. Esc закрывает слои по одному, сверху вниз.
7. **Своё, без заимствований.** Шрифт Manrope (Golos / Onest на выбор), свои значки 24×24,
   абстрактные обложки. Никаких SF Symbols, SF Pro и чужих логотипов. Название и артист можно
   выделить и скопировать (`.sel`).

## Цвет

Единственный вход — `--cover` (цвет обложки). Он зарегистрирован через `@property` как `<color>`,
поэтому плавно перетекает за `--dur-4` при смене трека. Все цвета получаются через
`oklch(from var(--cover) L C H)`:

- **L** (светлота) — задаём сами, иногда `clamp` от светлоты обложки.
- **C** (насыщенность) — берём у обложки и ограничиваем `min(…)`.
- **H** (оттенок) — оставляем как есть.

`--tint: 0.42` — насколько поверхности подкрашены обложкой; 0 — нейтральный интерфейс.

### Тёмная тема (основная)

| Токен | Формула | Роль |
|---|---|---|
| `--bg` | `0.165  min(c·tint, .035)  h` | фон окна |
| `--bg-side` | `0.145  min(c·tint, .035)  h` | левая панель ПК |
| `--surface-1` | `0.205  min(c·tint, .04)  h` | карточки, мини-плеер iPhone |
| `--surface-2` | `0.25  min(c·tint, .045)  h` | поля, вложенные блоки |
| `--bar-bg` | `0.185  min(c·tint·.8, .04)  h` | нижняя панель плеера ПК |
| `--hover` / `--press` | белый 6 % / 10 % | наведение / нажатие |
| `--text-1/2/3/off` | `oklch(.97 0 0)` · 64 % · 42 % · 26 % | текст по важности |
| `--border` | белый 8 % | разделители |
| `--accent` | `clamp(.74, l, .86)  min(c·1.5, .2)  h` | кнопки, активная вкладка, прогресс |
| `--accent-soft` | `--accent` 16 % | подложка чипов |
| `--on-accent` | `oklch(.17 0 0)` | текст на акценте |
| `--hero-a` → `--hero-b` | `clamp(.38, l, .5)  min(c·1.1, .17)` → `.22  min(c, .07)` | градиент героя Sonar Mix |
| `--player-a` → `--player-b` | `clamp(.34, l·.8, .48)  min(c, .15)` → `.15  min(c·.5, .05)` | фон полноэкранного плеера |
| `--hero-ink`, `--player-ink` | `oklch(.98 0 0)` | текст на окрашенном |
| `--ring` | `clamp(.8, l, .92)  min(c·1.3, .18)  h` | кольца Sonar Mix и подсветка на герое |
| `--danger` | `oklch(.58 .21 25)` | удаление |

### Светлая тема

Меняются только поверхности, текст и акцент. Герой и плеер остаются окрашенными и тёмными.

| Токен | Формула |
|---|---|
| `--bg` | `0.985  min(c·tint·.4, .012)  h` |
| `--bg-side` | `0.962  min(c·tint·.5, .016)  h` |
| `--surface-1` | `0.952  min(c·tint·.5, .016)  h` |
| `--surface-2` | `0.915  min(c·tint·.5, .02)  h` |
| `--bar-bg` | `0.975  min(c·tint·.4, .014)  h` |
| `--text-1/2/3/off` | `oklch(.19 0 0)` · 62 % · 45 % · 28 % |
| `--hover` / `--press` / `--border` | чёрный 4,5 % / 8 % / 8 % |
| `--accent` | `clamp(.44, l, .56)  min(c·1.5, .2)  h` (темнее — читается на белом) |
| `--on-accent` | `oklch(.99 0 0)` |

### «Тема под обложку» выключена

`data-cover='off'`: `--cover` фиксирован на `oklch(.6 .12 250)` (синий Sonar), `--tint: 0.2`.

### Тени

- `--shadow-cover` — длинная тень под обложкой, окрашенная её же оттенком:
  тёмная тема `0 24 48 -18  oklch(from cover .08 c h / .7)`, светлая — `.3 c h / .55`.
- `--shadow-pop` — меню и листы: `0 16 40 -12` чёрный 60 % (светлая — 22 %) плюс кольцо `--border`.

- **Каркас iPhone:** поля 20, статус 54, вкладки 84, мини-плеер 62 (на 92 от низа).

## Движение

| Токен | Длительность | Где |
|---|---|---|
| `--dur-1` | 140 мс | наведение, нажатие (scale .92–.985) |
| `--dur-2` | 220 мс | переключатели, чипы, смена значка пуск ⇄ пауза, закрытие слоёв |
| `--dur-3` | 320 мс | появление меню и оверлеев, смена страницы, экраны iPhone |
| `--dur-4` | 450 мс | смена цвета обложки, морф мини-плеер ⇄ плеер, 3D-открытие настроек |

| Кривая | Значение | Для чего |
|---|---|---|
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` | появление: быстрый старт, мягкая посадка, без перелёта |
| `--ease-std` | `cubic-bezier(.4, 0, .2, 1)` | цвет, прозрачность, переключатели |
| `--ease-in` | `cubic-bezier(.4, 0, 1, 1)` | уход со сцены |

Правило: **появление — `ease-out`, уход — `ease-in` и на ступень короче.**

### Ключевые кадры

| Что | Появление | Уход |
|---|---|---|
| Страница ПК | `page-in`: прозрачность + `translateY(8px)`, dur-3 out | — |
| Оверлей ПК (эквалайзер, итоги, Ctrl+K) | `ov-in`: `translateY(10px) scale(.985)`, dur-3 out | `ov-out`: `translateY(6px) scale(.99)`, dur-2 in |
| Полноэкранный плеер ПК | `full-in`: `translateY(5%)`, dur-3 out | `full-out`: `translateY(4%)`, dur-2 in |
| Настройки ПК | приложение уезжает: `perspective(2200) translateX(54%) rotateY(-15°) scale(.86)`, dur-4; панель — `set-in`: `translateX(-40px)`, dur-4 out | `set-out`: `translateX(-30px)`, dur-3 in |
| Меню трека | `menu-in`: `scale(.96) translateY(-4px)` от точки клика, dur-2 out | `menu-out`: `scale(.98)`, 160 мс in |
| Подменю, панели | `pane-in`: `translateY(6px)`, dur-2 out | — |
| Тост | `toast-in`: снизу на 12px, dur-3 out | `toast-out`: 8px, dur-2 in |
| Лайк | `like-pop`: `scale(.55)` → 1 с прозрачностью .4 → 1, без перелёта | — |
| Экран iPhone вперёд / назад | `ph-push` / `ph-pop`: ±24px + прозрачность, dur-3 out | — |
| Вкладка iPhone | `ph-fade`, dur-2 std | — |
| Лист меню iPhone | `sheet-in`: из `translateY(105%)`, dur-3 out; подложка проявляется | `sheet-out`, dur-2 in |
| Загрузка | `shimmer`: 1,4 с, бесконечно | — |
| Столбцы статистики | `bar-up`: снизу, dur-4, лесенкой | — |
| Итоги-истории | `story`: полоса прогресса 5 с | — |

**В такт треку** (`--bpm` трека, по умолчанию 90): эквалайзер в строке `60s / bpm`, кольца героя
`240s / bpm`, дрейф фона плеера `240s / bpm`, точки паузы в тексте `120s / bpm`. Пока трек на паузе,
всё стоит.

### Морф iPhone: мини-плеер ⇄ плеер (`js/ph/morph.js`)

1. Обложка мини-плеера (44×44, радиус 9) вырастает на место большой (337×337, радиус 16):
   `translate + scale` от точки мини к слоту, **450 мс `ease-out`**. Закрытие — обратно за **380 мс**.
2. Фон плеера (градиент `--player-a → --player-b`) проявляется за **320 мс `ease-std`**.
3. Части плеера всплывают лесенкой: `.pp-top`, `.pp-meta`, `.pp-prog`, `.pp-ctrls`, `.pp-vol`,
   `.pp-foot`. Каждая — 320 мс, первая через 70 мс, следующие через +28 мс.
4. На паузе большая обложка уменьшается до `scale(.86)` за dur-4.
5. Открыта панель текста или очереди (большой обложки нет) или включено «Меньше движения» —
   только прозрачность, 220 мс.

### «Меньше движения»

Системный `prefers-reduced-motion` или «Движение: Меньше» в настройках дают одно и то же:
`transition-property: opacity`, все `animation: none`, `--dur-4: 0`. 3D-открытие настроек
отключается — панель просто проявляется.

## Значки

64 значка в `icons/*.svg`, исходник — `js/art.js`, выгрузка — `node tools/export-icons.mjs`.

- Сетка 24×24, линия 1,75, скругления `round`, цвет `currentColor`.
- Залитые части (`fill="currentColor" stroke="none"`) — кнопки воспроизведения (пуск, пауза,
  следующий, предыдущий), залитое сердце и мелкие точки и ручки (more, info, eq, queue и т. п.).
- В Svelte — как есть; на iOS — как SwiftUI-пути, тем же путём, что `ios/scripts/gen-icons.mjs`.

**Подвижные части** — у них есть `id`, чтобы анимировать отдельно:

| Значок | id | Что двигается |
|---|---|---|
| `mix` | `wave1`, `wave2` | волны Sonar Mix расходятся |
| `heart`, `heart-fill` | `heart` | лайк (`like-pop`) |
| `play` | `play` | пуск ⇄ пауза: прозрачность + `scale(.6)`, dur-2 |
| `pause` | `bar1`, `bar2` | столбики паузы |
| `check` | `check` | галочка рисуется |
| `eq` | `knob1`–`knob3` | ручки эквалайзера ездят |
| `deep` | `wave1`–`wave3` | волны Sonar Deep |

## Состояния

У каждого экрана три состояния — переключаются «Состояние» на панели или `load=` в адресе:

- **Данные** — обычный экран.
- **Загрузка** — скелетоны той же формы, что и содержимое, с `shimmer`.
- **Пусто** — короткая фраза о том, что тут будет, плюс одна кнопка, что сделать.
