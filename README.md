# Sonar

Свой музыкальный плеер: SoundCloud + Яндекс Музыка в одном месте, свои лайки и смешанные
плейлисты, «Моя волна», статистика, синхронизация между устройствами.

- **iOS** — Swift / SwiftUI (первая платформа).
- **Windows** — Rust (позже).
- **Сервер** — Python (FastAPI) + Telegram-бот для входа.

Сборки — в [Releases](https://github.com/folzy1092/Sonar/releases). Приложение обновляется само.

Документация — в [docs/](docs/): [ТЗ](docs/TZ.md), [спека](docs/SPEC.md), [API](docs/API.md),
[база](docs/DB.md), [настройки](docs/SETTINGS.md), [карта проекта](docs/MAP.md),
[псевдокод](docs/PSEUDOCODE.md), [план](docs/ROADMAP.md).
