## Сервисы

| Сервис | Что работает |
|---|---|
| **SoundCloud** | вход окном внутри Sonar или своим ключом, поиск, лайки, плейлисты |
| **Яндекс Музыка** | вход по коду (`ya.ru/device`) или токеном, качество до FLAC |
| **YouTube Music** | поиск, медиатека, воспроизведение |
| **VK Музыка** | поиск, медиатека, воспроизведение |
| **Spotify** | вход, медиатека, поиск |
| **Локальные файлы** | папки с музыкой на ПК прямо в медиатеке |

Трек недоступен в одном сервисе — Sonar сам найдёт его в другом и сыграет оттуда.
Трек SoundCloud можно слушать в качестве Яндекса (FLAC / 320), если он там есть.

**Sonar Deep** — подписка на функции самого Sonar (объёмный звук 3D · 8D · 12D · 16D, реверб, расширенный пульт и др.),
тарифы Ping · Echo · Pod · Fleet на 1–4 места. Доступ к музыке и скачивание треков — бесплатно.
Оплата — на сайте [sonar.folzy.ru/pay](https://sonar.folzy.ru/pay) (заработает вместе с сервером).

## ПК и iPhone

**Windows** — основная платформа: всё из списка выше.

**iPhone** — та же структура разделов и настроек, свой вид: таб-бар-капсула, которая
сворачивается при прокрутке, тема под обложку, поле точек на Главной. Есть все сервисы,
Любимые и плейлисты, Sonar Mix, тексты, умные плейлисты, статистика, пульт для ПК,
виджет на экран «Домой», Siri и «Команды». Что пока только на ПК — [docs/PLATFORMS.md](docs/PLATFORMS.md).

## Установка

**Windows 10 / 11** — скачай [Sonar-setup.exe](https://github.com/folzy1092/Sonar/releases/latest/download/Sonar-setup.exe)
и запусти. Дальше Sonar обновляется сам.

**iPhone (iOS 18+)** — скачай [Sonar.ipa](https://github.com/folzy1092/Sonar/releases/download/ios-latest/Sonar.ipa)
и подпиши своей парой сертификата (.p12 + .mobileprovision, например в ESign или Feather). Потом укажи
ту же пару в «Профиль → Система → Обновления → Сертификат» — и обновления будут ставиться из приложения.

Сервисы подключаются в «Настройки → Сервисы». Ключи хранятся только на твоём устройстве.

План — [docs/ROADMAP.md](docs/ROADMAP.md).

## Устройство репозитория

```
windows/   ПК-клиент: Tauri 2 (Rust) + Svelte 5 + TypeScript
ios/       iPhone-клиент: SwiftUI, проект из XcodeGen
server/    Python: FastAPI и Telegram-бот (ждёт хостинга)
site/      sonar.folzy.ru — Astro, ru / en / uk
docs/      ТЗ, спека, API, база, настройки, карта проекта
brand/     знак Sonar и знаки сервисов
updates/   объявления обновлений и changelog для приложений
```

Подробная карта — [docs/MAP.md](docs/MAP.md). Сборки собирает GitHub Actions: каждый пуш в `main`
выпускает релиз (Windows — `windows-v<версия>`, iPhone — `ios-build-<N>`), сайт выкладывается на GitHub Pages.

## Безопасность

Код открыт для чтения, чтобы было видно, что внутри нет ловушек.
Ключи сервисов лежат в системном хранилище (Windows Credential Manager, Keychain на iPhone) и в
логи не пишутся. Сервер не хранит и не проксирует аудио; пароли там будут только в виде argon2-хэша,
токены — зашифрованы. Подробно — [docs/SPEC.md](docs/SPEC.md#6-безопасность).
