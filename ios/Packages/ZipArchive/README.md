# ZipArchive

Сторонний код: [SSZipArchive](https://github.com/ZipArchive/ZipArchive) (MIT, `LICENSE`) и внутри —
[minizip-ng](https://github.com/zlib-ng/minizip-ng) (лицензия zlib, `Sources/ZipArchive/minizip/LICENSE`).
Взят из Shadow (`third-party/ZipArchive`) без изменений: тот же набор файлов и флаги `HAVE_*`.
Sonar распаковывает им скачанную IPA и упаковывает подписанную обратно (`Update/SelfUpdater.swift`).
