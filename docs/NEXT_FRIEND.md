## 1. Новинки на iPhone

На ПК готово: `release_feed` (windows/src-tauri/src/commands.rs), `lib/new-releases.svelte.ts` (свежее за
неделю, «виденное» — в localStorage, тест рядом), колокольчик `app/ReleasesBell.svelte`, `notify.releases`.

iPhone:
- Ядро: порт `release_feed` в `Core/Providers/MusicCore` — исполнители из Любимых (`LibraryStore`) →
  альбомы (`artistAlbums`) + свежие треки SoundCloud (`/users/{id}/tracks`, дата — `release_date` →
  `display_date` → `created_at`), только с датой, новые первыми.
- Фон: `BGAppRefreshTask` (Info.plist `BGTaskSchedulerPermittedIdentifiers` + `UIBackgroundModes: fetch`),
  раз в несколько часов (когда — решает iOS; смахнули из списка — не будит) → новое и не виденное →
  **локальное** уведомление `UNUserNotificationCenter`: «У {artist} вышел «{title}»». Пуши APNs — только с
  сервером. Разрешение на уведомления — спросить при включении тумблера, не при запуске.
- Тумблер «Новинки исполнителей» — в настройках уведомлений iPhone (ключ `notify.releases`, по умолчанию вкл).
- Тап по уведомлению → альбом / трек (deep link `sonar://…`, `App/DeepLink.swift`).
- Логика «свежее и не виденное» — с XCTest (как `new-releases.test.ts`).

## 2. «Схожесть» вкуса в профиле друга (ПК, потом iPhone)

Образец — скрин владельца (блок «Совместимость» → у нас **«Схожесть»**). В профиле друга:
- круглые аватары обоих + крупно процент; ≥ 85 % — подпись «Очень похожие вкусы» (ниже — «Похожие вкусы» /
  «Разные вкусы», пороги 60 / 85);
- «Общие исполнители» — строка аватаров + имена; **клик по исполнителю открывает его страницу**;
- «Общие треки» — до 3–5 строк, **клик играет трек**;
- раскладка опирается на текущий `pages/profile/ProfileView.svelte` (не копировать скрин, а занять место так
  же плотно: две колонки «Схожесть» | «Артисты»).
- Процент: взвешенное пересечение топ-исполнителей (вес — доля прослушиваний) + общие лайки; формулу —
  в `lib/` с тестами, одинаковую для ПК и iPhone.
- Друзей пока нет (с сервером): сделать компонент + расчёт + договор `GET /users/{username}/taste` в
  `docs/API.md`; до сервера показывать на демо-данных только в предпросмотре «Друг» (`ProfilePage.svelte`).

## Правила, на которых легко споткнуться

- Строки интерфейса — `t('русский')` + перевод на **en, uk, es, de, pl** (`src/i18n/<язык>/*.ts`), iPhone —
  `cd ios/scripts && node gen-i18n.mjs`.
- Многие файлы с CRLF: `sed`/замены по `\n` молча не срабатывают — правь Edit-ом или нормализуй.
- Перед коммитом: `cd windows && npm run check && npm test`, `cd src-tauri && CARGO_TARGET_DIR=target-check cargo test`.
- Коммиты — от Folzy, без следов агента. Пуш в `main`.
