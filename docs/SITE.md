# Сайт Sonar — `sonar.folzy.ru` (спека, 2026-11-18)

Задание для отдельной сессии агента. Сайт — визитка сервиса, скачивание, оплата Sonar Deep, юр-страницы,
профиль по ссылке и статус. Ориентир по **структуре** — `dotify.fun` (друг владельца разрешил опираться на
Dotify), но вид — **свой стиль Sonar**: тёмный, спокойный, «не слопно», знак и цвета из `brand/`, шрифты
те же, что в приложении (`windows/src/theme/fonts.css`, fontsource). Ничего не копировать дословно — ни
текстов, ни картинок, ни разметки.

## 1. Техника

- Папка `site/` в монорепо, хостинг **GitHub Pages**, домен `sonar.folzy.ru` (`site/CNAME`; DNS-запись
  `sonar` → `folzy1092.github.io` добавляет владелец). Деплой — workflow `.github/workflows/site.yml` на пуш в
  `main` с изменениями `site/**`.
- Статика без сервера: **Astro** (или Vite + ванильный TS) → чистый HTML/CSS, минимум JS. Никаких трекеров,
  аналитики и сторонних cookie → баннер cookie **не нужен** (написать это в `/privacy`).
- Языки: ru (по умолчанию), en (`/en/…`), uk (`/uk/…`); переключатель флагом в шапке, как в приложении.
- Адаптив: телефон 375 px — без горизонтальной прокрутки, шапка сворачивается в меню.
- Доступность: альт-текст у картинок, контраст ≥ 4.5:1, всё доступно с клавиатуры, видимый фокус.
- **Анимации обязательны** (CLAUDE.md «Всё анимировано»): появление секций каскадом при прокрутке,
  наведение и нажатие, переключение вкладок индикатором, смена тарифа и цены плавно. `prefers-reduced-motion`
  — только прозрачность.
- Данные, которые меняются, — из JSON в репо, не зашивать в разметку:
  `updates/update.json` (версия Windows), `updates/ios-update.json` (iOS), цены — `site/data/plans.json`
  (зеркало `windows/src/lib/subscription.ts`: 100 / 190 / 285 / 380 ₽ в месяц — утверждено владельцем, скидки за срок — черновик), changelog — `updates/changelog.json`.

## 2. Шапка и подвал (на всех страницах)

- **Шапка:** знак Sonar + «Sonar» → `/`; ссылки «Возможности» (`/#features`), «Скриншоты» (`/#shots`),
  «Вопросы» (`/faq`), «Статус» (`/status`), «Sonar Deep» (`/pay`); флаг языка.
- **Подвал:** © 2026 Sonar · Канал `t.me/SonarUpdates` · Бот `t.me/SonarMusicApp` · «Баг или идея» (бот,
  кнопка «Баг / Идея») · Вопросы · Условия (`/terms`) · Конфиденциальность (`/privacy`) · Условия подписки
  (`/subscription`) · Лицензии (`/licenses`) · ссылки на скачивание Windows / iOS.

## 3. Главная `/`

1. **Герой.** Заголовок (вариант: «Вся твоя музыка — в одном плеере»), подзаголовок про SoundCloud, Яндекс
   Музыку, YouTube Music, VK Музыку, Spotify и свои смешанные плейлисты. Кнопка «Скачать» (определяет ОС:
   Windows → `releases/latest/download/Sonar-setup.exe`, iPhone → `/download#ios`). Ряд знаков сервисов из
   `brand/icon/*` (цветные, `fill` атрибутами). Справа / под заголовком — живой фон: поле точек как герой
   Главной на iPhone (`ios/Sonar/Features/Home/SonarField.swift`) — canvas, лёгкий.
2. **Скриншоты** `#shots` — ПК (Главная, плеер с текстом, настройки) и iPhone (Главная, плеер). Скрины
   **без личных данных** (не из `reference/`), с альт-текстом. Карусель листается мышью и пальцем.
3. **Возможности** `#features` — сетка карточек (каждая со своей мини-иллюстрацией, не просто иконка):
   - Смешанные плейлисты и свои лайки — треки из разных сервисов в одном списке;
   - Тексты песен — караоке по словам, размер и стиль (иллюстрация: строки с подсветкой);
   - Твой звук — эквалайзер, скорость Slowed / Sped up, 3D · 8D · 12D · 16D и реверб (пометка Sonar Deep);
   - Свой стиль — тема под обложку, готовые стили, шрифты;
   - Резерв из другого сервиса — трек недоступен, Sonar находит его в другом;
   - Импорт по ссылке — Spotify, YouTube Music, VK, Яндекс, SoundCloud, Apple Music;
   - Без интернета — кэш, скачанное, файлы с компьютера (MP3 / FLAC — бесплатно);
   - Пульт с iPhone — управление Sonar на ПК по Wi-Fi;
   - Статистика и итоги месяца / года.
4. **Sonar Deep** — короткий блок: «Музыка бесплатно. Deep — для тех, кто хочет больше» + 4–5 главных плюсов
   + кнопка «Тарифы» → `/pay`.
5. **Скачать** `#download` — вкладки **Windows** (EXE-установщик, версия из `update.json`) и **iOS** (IPA
   `releases/download/ios-latest/Sonar.ipa` + «Как установить»: подпись своим P12 + mobileprovision, ссылка на
   `/faq#ios`). macOS / Linux / Android — **не показывать**, их нет. Ссылки «Все версии» (Releases) и
   «Что нового» (changelog).

## 4. Оплата `/pay` (по референсу владельца — страница оплаты Dotify, скрины в чате 2026-11-18)

Приложение открывает `/pay?plan=<ping|echo|pod|fleet>&period=<1m|3m|6m|12m>&u=<username>` — страница
сразу показывает этот выбор.

- Слева: заголовок «Sonar Deep»; сегмент тарифов **Ping · Echo · Pod · Fleet** (1–4 места, подписи «Только ты»,
  «Ты и ещё 1» …); «Срок» — 4 карточки 2×2 с ценой и скидкой (−N %); «Аккаунт» — поле `@username` (из `u`,
  можно поправить); «Способ оплаты» — карточки платёжек (какие — решит владелец; до выбора — одна карточка
  «Скоро»); кнопка «Оплатить N ₽»; под ней «Оплачивая, ты принимаешь условия подписки и соглашение» (ссылки).
- Справа (на телефоне — снизу, шторкой): карточка «Подписка на 1 месяц / Sonar Deep Echo / Ты и ещё 1» +
  список «Что входит» (прокручивается внутри, ~14 пунктов из `PERKS`), цена, способ оплаты, «Подписка придёт
  на аккаунт @username».
- Пока платёжки нет — кнопка неактивна с подписью «Оплата скоро», страница всё равно рабочая.
- Ниже — честный блок «Бесплатно без подписки»: музыка, лайки, плейлисты (до 5), перенос до 500 треков за
  раз, синхронизация, **скачивание треков**.
- Секреты платёжки — **только** на сервере / в секретах; сайт лишь перекидывает на страницу оплаты провайдера.

## 5. Остальные страницы

- **`/faq`** — «Частые вопросы» (ориентир — `dotify.fun/faq`, вопросы свои, по Sonar): сверху **поиск по
  вопросам** (нет совпадений — «Ничего не нашлось» + ссылка в бота), ниже **аккордеон** (раскрытие анимировано),
  вопросы сгруппированы заголовками, у каждого — якорь (`/faq#ios`), ссылкой можно поделиться:
  - *Начало:* Где скачать Sonar (официальные ссылки — только сайт, Releases и `@SonarUpdates`; остальное —
    подделки) · Что такое Sonar и чем отличается от приложений сервисов · Бесплатно ли · Как оформить Sonar Deep.
  - *Установка:* Как поставить на iPhone (`#ios`: своя подпись P12 + mobileprovision, «Доверять» в настройках,
    обновление сертификатом в «Система → Обновления») · Предупреждение SmartScreen / антивирус (нет платной
    подписи Authenticode; качай только с официальных мест) · Белый экран при запуске (WebView2 Runtime, Ctrl+R,
    очистка кэша).
  - *Сервисы:* Как подключить SoundCloud / Яндекс / YouTube Music / VK / Spotify · Почему Яндекс не работает за
    границей · Треки не играют / «Проверьте сеть» (резервный сервис, VPN, Zapret) · Импорт плейлистов по
    ссылке · Где хранятся токены сервисов.
  - *Возможности:* Discord RPC · Пульт с iPhone · Тексты песен не находятся · Локальные файлы.
  - *Аккаунт и данные:* Приватность профиля · Как удалить данные · Поддержка и баг-репорт (как снять лог:
    «Отправить лог» после сбоя, бот «Баг / Идея», что указать в обращении).
- **`/status`** — «Статус сервисов» (ориентир — `dotify.fun/status`, у них пока только заготовка без данных —
  сделать лучше): подзаголовок «Состояние Sonar и музыкальных сервисов»; сверху **общая плашка** («Всё работает»
  / «Есть сбои» / «Не работает» цветом); блок **«Sonar»** — Основной · Бот · Хранилище · Сайт; блок
  **«Сервисы»** — «Поиск и звук»: SoundCloud, Яндекс Музыка, YouTube Music, VK Музыка, Spotify; «Тексты»: lrclib,
  Genius; «Другое»: Last.fm, Telegram; «Только импорт»: Apple Music. У каждого — знак, название, статус точкой и
  словом, **полоски за 30 дней** с аптаймом в % (наведение — дата и что было), **легенда цветов**, «обновлено
  N мин назад», ниже **история сбоев**. Данные — `GET /status` (SPEC §3.11); до сервера — заготовка «Статус
  появится вместе с сервером» без выдуманных цифр (как у Dotify сейчас «Нет данных»).
- **`/@username`** — публичный профиль (`PublicProfile`, `windows/src/lib/public-profile.ts`; API —
  `GET /public/users/{username}`, docs/API.md). Учитывает приватность (`privacy.*`) — скрытое сервер просто не
  отдаёт. До сервера — «Профили заработают вместе с сервером». GitHub Pages: маршрут `/@…` через `404.html`
  со скриптом-роутером.
- **`/privacy`** — какие данные (логин, @username, аватар, лайки, плейлисты, история прослушиваний для
  статистики, токены сервисов — зашифрованы на сервере), зачем, где хранятся (сервер в Германии), кому
  передаются (сервисам музыки — только твои запросы; Discord / Last.fm — если включил), cookie нет, срок
  хранения, **как удалить всё** (кнопка в приложении / бот), контакты.
- **`/terms`** — соглашение: Sonar — клиент к твоим аккаунтам сервисов, контент принадлежит правообладателям
  и сервисам, ответственность за соблюдение правил сервисов — на пользователе, без гарантий доступности.
- **`/subscription`** — условия подписки: что входит, срок, продление (вручную, без автосписания, пока
  нет иного), возврат (сформулирует владелец), что будет при окончании (возвращаются бесплатные пределы,
  данные не удаляются).
- **`/delete`** — короткая инструкция «Как удалить аккаунт и все данные».
- **`/licenses`** — сторонние лицензии: шрифты (SIL OFL, fontsource), значки MingCute (Apache-2.0) и Tabler
  (MIT), hls.js (Apache-2.0), знаки Spotify / Apple Music — Simple Icons (CC0), Tauri и крейты Rust (список
  из `cargo about`/`license-checker`). Сам Sonar — проприетарная лицензия (`LICENSE`), не менять.

Юр-тексты агент пишет черновиком и помечает «черновик, не проверено юристом» — владелец решает, нужен ли юрист.

## 6. Чего на сайте нет

Отзывов, счётчиков пользователей, обещаний «скоро» без даты, тёмных паттернов (предвыбранные галочки,
скрытые платежи, таймеры «осталось 5 минут»), трекеров и баннера cookie.

## 7. Готово, когда

- Все страницы на трёх языках, адаптив 375–1440 px, Lighthouse ≥ 90 (Performance, Accessibility, SEO).
- `/pay` правильно читает `plan` / `period` / `u` и совпадает по ценам с `windows/src/lib/subscription.ts`
  (тест или скрипт сверки `site/data/plans.json`).
- Workflow `site.yml` деплоит, `sonar.folzy.ru` открывается (после DNS-записи владельца).
- ROADMAP: отметить пункт «Сайт», в CLAUDE.md — где лежит сайт и как он собирается.
