# Настройки ПК — что подсмотрели у Dotify 2.4 (скрины владельца 2026-11-18)

Черновик спеки, пополняется по скринам владельца. Dotify — только ориентир (друг разрешил опираться),
вид — свой стиль Sonar. Вход через обычный браузер **не делаем** (решение владельца 2026-11-18: остаётся как
есть — Яндекс и Last.fm в браузере, SoundCloud и Spotify — окном внутри Sonar или вставкой ключа).

## Боковое меню (у нас уже есть с 2026-11-18, дотянуть)

- Карточка профиля сверху: аватар с кольцом, имя, @username, **кнопка «Выйти»** справа (с сервером).
- Под ней — **плашка уровня**: значок с числом (уровень), «240 треков», строка любимого (?) и полоска
  прогресса до следующего уровня. У нас — решить, что считать уровнем (прослушанные часы / треки), до
  сервера локально из `plays`.
- Группы у Dotify: **Аккаунт** (Безопасность, Приватность, Подписка, Вкус, Статистика, Уведомления),
  **Приложение** (Общее, Аудио, Хранилище, Интеграции, Прокси, Клавиши, О приложении), **Интерфейс** (Вид,
  Плеер, Мини плеер, Оверлей, Кастом, Мастерская). Нам: добавить «Вкус» (оттенки вкуса), «Уведомления»,
  «О приложении» отдельным пунктом (сейчас внизу «Общего»); Прокси, Кастом, Мастерская — **не делаем**.
- Поиск внизу меню — есть.

## Уведомления (Аккаунт → Уведомления, с сервером)

- Капсулы-фильтры: **Все · Друзья · Другое**.
- Список по дням («10 ноября»): значок или аватар, заголовок + время, текст, под ним итог («Вы теперь
  друзья»); непрочитанное — точка справа.
- Виды: заявка в друзья (Принять / Отклонить → итог), подписка активирована / заканчивается, трек от
  друга (ЛС), обновление Sonar.

## Плеер (Интерфейс → Плеер) — одна длинная страница вместо «Вид» + «Очередь»

1. **Стиль плеера** — живой пример сверху (обложка, строки, ползунок, точки) + капсулы Обычный · Пластинка ·
   Большой (у нас есть стили — сделать пример живым, как у них).
2. Выравнивание заголовка (три значка) — есть. Аватарки артистов — есть.
3. **Визуализатор** — карточки-превью: Выключено · Полоса · На обложке · На фоне; **Стиль** — Волна · Столбцы.
4. **Тип ползунка** — карточки-превью: Обычный · Тонкий · Плавный · **Переливы** · **Волновой** (волна
   громкости трека, как в SoundCloud). Новые для нас — Переливы и Волновой.
5. **Обложка:** Канвас — не делаем (CLAUDE.md); Позиция обложки Слева / Справа — есть; **Обложка в
   обложке** (малая внутри большой, размытой) — новое.
6. **Очередь** (переехала сюда из отдельного раздела): При запуске — Ничего / Трек / Очередь; Показывать
   очередь; Предпросмотр следующего трека; Положение очереди Снизу / Слева / Справа; Вид очереди —
   Обычный / Развёрнутый (превью); Продолжать очередь (подборкой); **Добавлять следующие** (включил трек из
   списка — в очередь встают и следующие за ним).

## Мини плеер

- **Стиль** — карточки с настоящей обложкой играющего трека: Полный · Закруглённый · Гибрид … (у нас схемы —
  взять живые превью).
- Позиция — **четыре значка** (сверху / снизу / снизу во всю ширину / плавающий) вместо плиток.
- **Фон** — Тема · Обложка (размытая) · Цвет обложки; превью с обложкой.
- **Прогресс** — можно выбрать **несколько**: Линия · Фоном · Вокруг обложки.
- Обложка — По умолчанию / Круглая; Форма — По умолчанию / Капсула.

## Оверлей (у нас «не делаем» с 2026-11-14 — владелец смотрит снова, решение за ним)

- **Режим** — карточки: Отключен · Полноэкранный · Остров · Карточка («маленький плеер поверх других
  программ и игр»). У нас уже есть мини-окно поверх всех окон (`mini.rs`) — оверлей = его режимы.
- **Появляться само** — разворачивается, когда окно Sonar свёрнуто или закрыто.
- **Окно:** Форма — Квадратная / Скруглённая; **Положение на экране** — сетка 3×3 точек, плашка-пример
  перетаскивается в нужную точку.
- **Размер и прозрачность** — ползунки-полосы с подписью внутри: Непрозрачность 90 %, Масштаб 100 %,
  Ширина 340 px, Высота 58 px.

## Общие приёмы вида

- Карточки-превью вместо голых капсул везде, где выбор визуальный; выбранная — светлее, подпись жирнее.
- Ползунок-полоса: заливка с названием внутри, значение справа (как «Непрозрачность 90 %»).
- Группы — заголовок серым над карточкой («Окно», «Размер и прозрачность»), внутри строки без разделителей.
