# Настройки ПК — что подсмотрели у Dotify 2.4 (скрины владельца 2026-11-18)

Черновик спеки, пополняется по скринам владельца. Dotify — только ориентир (друг разрешил опираться),
вид — свой стиль Sonar. Вход через обычный браузер **не делаем** (решение владельца 2026-11-18: остаётся как
есть — Яндекс и Last.fm в браузере, SoundCloud и Spotify — окном внутри Sonar или вставкой ключа).

## Боковое меню (у нас уже есть с 2026-11-18, дотянуть)

- Карточка профиля сверху: аватар с кольцом, имя, @username, **кнопка «Выйти»** справа (с сервером).
- Под ней — **плашка уровня**: значок с числом (уровень), «240 треков», строка любимого (?) и полоска
  прогресса до следующего уровня. У нас — решить, что считать уровнем (прослушанные часы / треки), до
  сервера локально из `plays`.
- Группы у Dotify: **Аккаунт** (Безопасность, Приватность, Подписка, Вкус, Статистика, Уведомления),
  **Приложение** (Общее, Аудио, Хранилище, Интеграции, Прокси, Клавиши, О приложении), **Интерфейс** (Вид,
  Плеер, Мини плеер, Оверлей, Кастом, Мастерская). Нам: добавить «Вкус» (оттенки вкуса), «Уведомления»,
  «О приложении» отдельным пунктом (сейчас внизу «Общего»); Прокси, Кастом, Мастерская — **не делаем**.
- Поиск внизу меню — есть.

## Уведомления (Аккаунт → Уведомления, с сервером)

- Капсулы-фильтры: **Все · Друзья · Другое**.
- Список по дням («10 ноября»): значок или аватар, заголовок + время, текст, под ним итог («Вы теперь
  друзья»); непрочитанное — точка справа.
- Виды: заявка в друзья (Принять / Отклонить → итог), подписка активирована / заканчивается, трек от
  друга (ЛС), обновление Sonar.

## Плеер (Интерфейс → Плеер) — одна длинная страница вместо «Вид» + «Очередь»

1. **Стиль плеера** — живой пример сверху (обложка, строки, ползунок, точки) + капсулы Обычный · Пластинка ·
   Большой (у нас есть стили — сделать пример живым, как у них).
2. Выравнивание заголовка (три значка) — есть. Аватарки артистов — есть.
3. **Визуализатор** — карточки-превью: Выключено · Полоса · На обложке · На фоне; **Стиль** — Волна · Столбцы.
4. **Тип ползунка** — карточки-превью: Обычный · Тонкий · Плавный · **Переливы** · **Волновой** (волна
   громкости трека, как в SoundCloud). Новые для нас — Переливы и Волновой.
5. **Обложка:** Канвас — не делаем (CLAUDE.md); Позиция обложки Слева / Справа — есть; **Обложка в
   обложке** (малая внутри большой, размытой) — новое.
6. **Очередь** (переехала сюда из отдельного раздела): При запуске — Ничего / Трек / Очередь; Показывать
   очередь; Предпросмотр следующего трека; Положение очереди Снизу / Слева / Справа; Вид очереди —
   Обычный / Развёрнутый (превью); Продолжать очередь (подборкой); **Добавлять следующие** (включил трек из
   списка — в очередь встают и следующие за ним).

## Мини плеер

- **Стиль** — карточки с настоящей обложкой играющего трека: Полный · Закруглённый · Гибрид … (у нас схемы —
  взять живые превью).
- Позиция — **четыре значка** (сверху / снизу / снизу во всю ширину / плавающий) вместо плиток.
- **Фон** — Тема · Обложка (размытая) · Цвет обложки; превью с обложкой.
- **Прогресс** — можно выбрать **несколько**: Линия · Фоном · Вокруг обложки.
- Обложка — По умолчанию / Круглая; Форма — По умолчанию / Капсула.

## Оверлей (у нас «не делаем» с 2026-11-14 — владелец смотрит снова, решение за ним)

- **Режим** — карточки: Отключен · Полноэкранный · Остров · Карточка («маленький плеер поверх других
  программ и игр»). У нас уже есть мини-окно поверх всех окон (`mini.rs`) — оверлей = его режимы.
- **Появляться само** — разворачивается, когда окно Sonar свёрнуто или закрыто.
- **Окно:** Форма — Квадратная / Скруглённая; **Положение на экране** — сетка 3×3 точек, плашка-пример
  перетаскивается в нужную точку.
- **Размер и прозрачность** — ползунки-полосы с подписью внутри: Непрозрачность 90 %, Масштаб 100 %,
  Ширина 340 px, Высота 58 px.

## Общее (Приложение → Общее)

- Карточка: **Язык** — три флага-капсулы; **Платформа** — значки сервисов (откуда волна и рекомендации).
- **Медиатека:** Добавление — В начало / В конец; **Синхронизировать** — кнопка-обновить справа (с
  сервером); **Общий кэш треков** — не делаем (сервер аудио не хранит).
- **Запуск:** Автозапуск, Сворачивать в трей, **Экономия ресурсов** — Выключено / При сворачивании / В фоне
  (капсулы под строкой). У нас всё это есть — свести в такие же три карточки.

## Аудио (Приложение → Аудио)

- **«Куда выводить звук?»** — список устройств строками (значок колонки + имя), выбранное подсвечено, вместо
  плиток в ряд.
- **«Какое качество?»** — строки: значок, название, справа **крупно число** и мелко `kbps` (192 · 256 · 320 ·
  1411); выбранная — ярче. У нас ещё YouTube Music — тем же видом.
- **Громкость и переходы:** Нормализация, Бесшовное, Кроссфейд, **Тише во время звонков** — есть у нас все.

## Хранилище (Приложение → Хранилище)

- Сверху карточка: **кольцо** с общим размером («54.7 MB») и справа «Что очистить?» — строки с галочкой,
  названием, размером и полоской доли: Треки · Обложки · Прочее.
- **Кеширование треков** — переключатель отдельной карточкой.
- **Данные:** История поиска — «Очистить»; **Настройки треков** (скорость, эквалайзер, сдвиг текста,
  сохранённые для отдельных треков) — «Сбросить».
- Внизу большая кнопка **«Очистить 54.7 MB»** — сумма отмеченного.

## Клавиши (Приложение → Клавиши)

- Капсулы: **В приложении · Поверх окон · Везде** (где действует сочетание).
- Группы **Плеер** (пауза, след./пред., ±5 с, перемотка, громкость, звук, перемешивание, повтор, лайк),
  **Навигация** (поиск `/`, текст `Ctrl+L`, очередь `Ctrl+Q`, настройки `Ctrl+,`, запустить волну),
  **Окно и оверлей** (оверлей `Ctrl+O`, поверх окон `Ctrl+T`).
- Сочетание — клавиши-«кнопки» справа, `—` если не задано; у изменённого — значок «сбросить» (↻).

## О приложении (Приложение → О приложении, отдельный пункт)

- По центру знак и название. Карточки:
  1. **Версия** — «Последняя версия» / «Доступно обновление», номер справа.
  2. Приглашения (с сервером) · **Бета-версии** (канал обновлений) · **Платежи** (история, с сервером).
  3. Ссылки наружу со значком ↗: Сайт · Телеграм · Подписка · Соглашение · Конфиденциальность.
  4. **Сбросить настройки** (с подтверждением).

## Вид (Интерфейс → Вид)

**Правило владельца (2026-11-18): никакой прокрутки вбок, если варианты помещаются.** У Dotify шрифты,
цвета, визуализатор, ползунок и стиль вкладок листаются вправо — у нас то же **сеткой**, всё видно сразу.

- **Тема** — Тёмная / Светлая / Системная (капсулы справа).
- **Цвет** — оставить как у нас было (наши готовые темы и «Под трек»), только раскладка сеткой, без
  прокрутки. У Dotify: Под трек · Neutral · AMOLED · Crimson · Nord … карточками-мини-окнами.
- **Прозрачность** — кнопка «Выбрать» (стекло включается само со своим фоном).
- **Текст:** Шрифт — капсулы-группы Система · Модерн · Засечки · Моно, под ними **сетка 4×4 (или 4×5)**
  карточек «Aa + название» (у Dotify — ряд с прокруткой); Размер шрифта — 12 · 14 · 16 Авто · 18 · 20;
  Жирность — Авто · 400 · 500 · 600 · 700.
- **Форма:** Скругление углов — живой пример (карточки, строки, кнопка) + Нет · Маленькое · Среднее ·
  Большое; **Показывать площадки** — значок сервиса рядом с длительностью трека; **Кнопки окна** — живой
  пример окна + **Авто · Windows · macOS** (Linux не нужен — его сборки нет); **Масштаб в окне** — 75 · 90 ·
  100 · 110 · 125 %; **Масштаб на весь экран** — Авто · 75 … 125 % (отдельно, когда окно развёрнуто).
- **Вкладки** (у нас — отдельный пункт «Вкладки», можно влить сюда): Позиция — четыре значка (сверху,
  снизу, слева, справа); **Стиль вкладок** — у Dotify 5 (По умолчанию, Компактный, Полный, Круглый,
  Плавающий), «Полный» почти не отличается от «По умолчанию» — **у нас только различимые стили, все в один
  ряд без прокрутки**; Поиск — Сверху (вырез) / Окном; Подстраивать вкладки (в медиатеке список вместо
  вкладок); Скрытие элементов (неактивные панели прячутся).

## Плеер — раскладка (дополнение к разделу «Плеер» выше)

- Визуализатор (Выключено · Полоса · На обложке · **На ползунке**), его Стиль (Волна · Столбцы) и **Тип
  ползунка** (Обычный · Тонкий · Плавный · Переливы · Волновой) — места занимают мало: **все варианты сразу,
  сеткой, без прокрутки** (у Dotify — ряд вбок). Визуализатор «На ползунке» — новый для нас.

## Общие приёмы вида

- Карточки-превью вместо голых капсул везде, где выбор визуальный; выбранная — светлее, подпись жирнее.
- Ползунок-полоса: заливка с названием внутри, значение справа (как «Непрозрачность 90 %»).
- Группы — заголовок серым над карточкой («Окно», «Размер и прозрачность»), внутри строки без разделителей.
