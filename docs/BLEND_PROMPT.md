# Задание агенту: «Сведение» на ПК

Прочитай `CLAUDE.md`, `docs/HANDOFF.md` и **`docs/BLEND.md` целиком** — это спека, все решения владельца уже в
ней (§0 «Решения владельца»), заново их не обсуждай и владельца про технологии не спрашивай.

Делай «Сведение» — DJ-переходы между треками на ПК (Windows-клиент, `windows/`). iPhone не трогай (Э8 — потом).

Порядок — этапы из `docs/BLEND.md` §12, **по одному, каждый отдельным коммитом**, приложение после каждого рабочее:

1. **Э1** — своя цепочка звука на каждый дек (§3). Поведение не меняется: кроссфейд, эквалайзер, тон,
   реверб, выравниватель, Slowed звучат как раньше. Начинай с него.
2. **Э2** — анализ трека (§4–5): воркер на TS, `blend.rs`, миграция № 17 (если её уже кто-то занял — следующая
   свободная в `store/mod.rs` `MIGRATIONS`, поправь `docs/BLEND.md` §5 и `docs/DB.md`).
3. **Э3** — Camelot и планировщик (§7). **Э4** — кривые переходов и контроллер (§6, §8).
4. **Э5** — кнопка слева от скорости и «Аудио» (§10). **Э6** — «Свести для вечеринки» (§9). **Э7** — отладка, оценки, Deep (§10.3, §11).

Правила:
- Готовые анализаторы под GPL/AGPL (essentia, aubio) не брать, npm-пакеты и крейты под анализ не добавлять.
- Тесты из §14 — к каждому этапу; перед коммитом `cd windows && npm run check && npm test`, `cd windows/src-tauri && cargo test`.
- Строки — через `t()`, переводы на все 5 языков; всплывашки — только по клику; всё анимировано (`lib/motion.ts`).
- Проверочный exe — `CARGO_TARGET_DIR=src-tauri/target-check`, запущенный у владельца Sonar не закрывать.
- Перед пушем крупного этапа (Э4, Э5) — навык `ponytail-review` по диффу.
- Нашёл в спеке противоречие с кодом — поправь спеку в том же коммите и скажи владельцу.
- Конец сессии — отметить этапы `[x]` в `docs/BLEND.md` §12 и в ROADMAP, обновить CLAUDE.md, коммит от Folzy, пуш в `main`.
