## 1. Языки: испанский, немецкий, польский

Сейчас есть русский (основной), английский и украинский. Добавить:

| Код | В списке | Флаг |
|---|---|---|
| `es` | Español | Испания |
| `de` | Deutsch | Германия |
| `pl` | Polski | Польша |

Порядок в списке: Русский, English, Українська, Español, Deutsch, Polski.

**Где словари:**
- Windows: `windows/src/i18n/<язык>/*.ts`, как `en/` и `uk/` (те же файлы: `account.ts`, `app.ts`, … `yt.ts`).
  Тип языка и выбор языка — `windows/src/lib/i18n.svelte.ts` (`Lang`, разбор сохранённого значения),
  проверка полноты — `i18n.test.ts`.
- iOS: словари генерирует `ios/scripts/gen-i18n.mjs` из `windows/src/i18n` в `Core/I18n/Strings+Windows.swift`,
  своё для iOS — `Strings+iOS.swift`. Научить генератор новым языкам, добавить переводы в `Strings+iOS.swift`, XCTest.
- Сайт: `site/src/i18n/<язык>.ts`, `LANGS` в `site/src/i18n/index.ts` (пути `/es/…`, `/de/…`, `/pl/…`),
  проверка полноты — `coverage.test.ts`, sitemap и `hreflang`, переключатель языка в шапке.

**Как переводить:**
- Ключ — русская строка, как везде (`t('…')`, `tn` для множественного, `t('контекст::Слово')`).
- Тон — как в русском: на «ты», тепло, коротко. Испанский — `tú`, немецкий — `du`, польский — `ty`.
- Множественное — по правилам языка: в польском три формы (1 / 2–4 / 5+), как в русском; в немецком
  и испанском две. Проверить, что `tn` и `pluralIndex` на всех трёх платформах это умеют.
- Не переводить названия: Sonar, Sonar Deep, Ping / Echo / Pod / Fleet, «Моя волна» — по смыслу
  (как в `en`), названия сервисов — как у сервисов.
- Нет строки в словаре нового языка — показывать английскую, не русскую.
- Перевод полный, а не «самое заметное»: тесты полноты должны проходить для `es`, `de`, `pl`.
- Длинные немецкие слова: проверить, что кнопки, вкладки и капсулы не ломаются (перенос или сжатие,
  без обрезки посреди слова), прежде всего левая панель, настройки, плеер, мини-плеер.

**Выбор языка — сразу списком.** Языков становится шесть, в одну строку-переключатель (`Choice` в
`windows/src/pages/settings/General.svelte`) они не помещаются. Поэтому:
- Система → Общее → строка «Язык», справа текущий язык (флаг + название).
- Клик открывает список всех языков: флаг, название на самом языке, галочка у текущего.
- Список открывается и закрывается **только кликом**: выбор языка, клик по строке ещё раз или мимо списка.
  Без наведения.
- Появляется плавно, пункты каскадом (`lib/motion.ts`, `use:cascade`); «Меньше движения» — только прозрачность.
- Язык меняется на лету, как сейчас.
- iOS: строка «Язык» открывает лист со списком, такой же вид.
- Первый запуск — как сейчас: язык системы, если он есть в списке, иначе русский. iOS: добавить es / de / pl
  в распознавание языка системы.

## 2. Sonar Deep: видно, чем отличаются тарифы

Сейчас при переключении Ping · Echo · Pod · Fleet почти ничего не меняется. Список «Что входит» одинаковый,
а отличие — мелкая строка «Ты и ещё N человек» под «Sonar Deep Echo» в карточке справа. Её не замечают.

**Что сделать:**
- Под переключателем тарифов и **над** «Срок» — одна строка, мелким приглушённым текстом (как подпись
  под заголовком страницы), что даёт тариф:
  - Ping — «Deep только для тебя»
  - Echo — «Deep для тебя и ещё одного друга, у которого есть аккаунт Sonar»
  - Pod — «Deep для тебя и ещё двух друзей, у которых есть аккаунт Sonar»
  - Fleet — «Deep для тебя и ещё трёх друзей, у которых есть аккаунт Sonar»

  Число — из `seats` тарифа (`tn`, без зашитых строк под каждый тариф). Формы «друга / друзей» — по правилам
  каждого языка.
- При смене тарифа строка меняется плавно (короткое растворение, без прыжка высоты).
- **Не дублировать:** строку «Ты и ещё N человек» / «Только ты» под «Sonar Deep Echo» в карточке справа
  убрать. В карточке остаются «Подписка на …», название, «Что входит», цена, кнопка.
- Как друзья занимают места (по `@username`, приглашением), решается вместе с сервером и оплатой.
  Сейчас — только подпись.

**Карточка справа — без внутренней прокрутки.** Сейчас список «Что входит» прокручивается внутри
карточки, хотя под ней ещё полэкрана пустого места. Нужно:
- Карточка вытягивается по содержимому: весь список виден целиком, без полосы прокрутки внутри.
- Если окно ниже карточки — прокручивается вся страница, а не список.
- Левая колонка (тарифы и срок) и карточка выровнены по верху, как сейчас.

**Где:**
- Windows: `windows/src/pages/settings/Subscription.svelte` (`seatsLabel`, `.perks`), `lib/subscription.ts`.
- iOS: `ios/Sonar/Features/Account/SonarDeepView.swift` (`seatsLabel`, карточка), XCTest на подпись по числу мест.
- Сайт: `/pay` — `site/src/pages/[...lang]/pay.astro`, тарифы — `site/data/plans.json`. Та же строка под
  тарифами; в карточке справа (на телефоне — снизу) без «Ты и ещё 1»; список «Что входит» без прокрутки внутри.
  Поправить `docs/SITE.md` §4.
- Новые строки — через `t()`, с переводом на en, uk и новые es / de / pl.
