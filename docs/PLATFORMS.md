# Sonar — iOS, Android и Windows: что где

Правило: **одна структура на обеих платформах.** Те же разделы, те же названия, тот же
порядок, те же ключи настроек (`SETTINGS.md`). Отличается только то, чего физически нет на
другой платформе (жесты на телефоне, оверлей и трей на компьютере). Пользователь, который
знает одну версию, сразу находит всё в другой.

## Android = iOS (решение владельца 2026-11-16)

Android делается **в том же стиле, что iOS**, и по максимуму **идентично**: те же экраны, таб-бар,
разделы и настройки, анимации, жесты, тексты и порядок кнопок — чтобы мобильные версии развивались
вместе и правка в одной сразу переносилась в другую. Расхождения — только там, где их требует
система: системная кнопка «назад», уведомление с плеером (MediaSession), установка APK и
автообновление, разрешения. Каждое такое расхождение записывается здесь отдельной строкой.
Порядок работ не меняется: Windows → сервер → iOS → Android. Где в этом файле написано «iOS», для
Android верно то же самое, если рядом не сказано иначе.

## Главное окно Windows (`reference/pc/Screenshot_19..24`)

Окно без системной рамки, свои кнопки окна справа сверху (назад · свернуть · развернуть · закрыть).

- **Левая панель — узкая колонка иконок:** сверху лого и **Главная**; по центру **Плеер**
  (страница «сейчас играет»), **Поиск**, **Медиатека**; снизу **Настройки** и **аватар** с
  точкой «в сети». Активная иконка подсвечена акцентом.
- **Сверху — строка поиска** «Что включить?» (видна на Главной и Поиске), справа в ней
  переключатель источника (SoundCloud / Яндекс) и кнопка вставки ссылки.
- **Снизу — мини-плеер на всю ширину:** обложка, название, исполнитель с аватаром, ❤;
  по центру повтор · назад · пауза · вперёд · перемешать; справа капсула с рамкой:
  **кнопка скорости** (часы; клик по кругу 1× → Slowed 0.8× → Speed 1.25× → 1×, **без меню**, как в
  Dotify; тон меняется вместе со скоростью; включённый режим — слово «Slowed»/«Speed» вместо значка,
  ключ `player.speed_mode`), **громкость** (клик по значку открывает ползунок в капсуле, только
  следующий клик закрывает — **наведение ничего не открывает**; колесо мыши), ✓ (статус «в волне»/
  скачан), «T» текст или ▣ панель очереди. Решения владельца 2026-11-14. Пауза — простой значок без
  круга; прогресс в стиле «Гибрид» — фоном, **клик или протяжка по фону (мимо кнопок и текста) — перемотка**, как в Dotify; фон при этом не выглядит кнопкой (обычный курсор, без подсветки). **Обложка** мини-плеера открывает сразу полноэкранный плеер — при наведении на ней две диагональные стрелки.
- **Главная** (`20, 23`): шапка «Моя волна» (коллаж обложек, режим волны «Жёсткая»,
  большая кнопка ▶), «Доброй ночи, <аватар> <ник>» — карусель недавнего, «Релизы»,
  «Похожее» — горизонтальные карусели квадратных обложек со значком источника.
- **Медиатека** (`21`): вкладки Все / Плейлисты / Альбомы / Исполнители, строка «Вы вошли
  как <аватары сервисов> <имена>», карусели «Плейлисты >» (Любимые, Скачанные, свои) и
  «Исполнители >» (круглые), внизу слева кнопки + · импорт · обновить.
- **Крестик окна прячет Sonar в трей** (решение владельца 2026-11-14): музыка из очереди играет
  дальше, значок в трее — левый клик показывает окно, правый — меню «Открыть» · «Выход»
  (выход завершает процесс целиком). Сделано в W3 (`src-tauri/src/tray.rs`).
- **Название трека и исполнителя можно выделить мышью и скопировать** — в плеере и мини-плеере
  (класс `.selectable`); клик без выделения, как и раньше, открывает плеер / исполнителя. В меню
  трека — «Копировать название». Решение владельца 2026-11-14.
- **Клик по обложке на странице плеера** открывает полноэкранный плеер (W4); «T» в мини-плеере — тоже.
- **Боковые кнопки мыши** «назад/вперёд» листают историю страниц; в полноэкранном плеере и настройках «назад» их закрывает (W4).
- **Заставка** при запуске и Ctrl+R (как у Dotify): логотип проявляется из размытия, от него
  расходятся «сонарные» кольца, через ~0,9 с гаснет (`windows/index.html`). Решение владельца 2026-11-14.
- **Страница плеера** (`22`, сделана в W2 по этому скрину): слева обложка (❤ и ✓ на ней), справа название, исполнитель,
  ползунок, **волна громкости трека** (визуализатор), кнопки ⋮ · управление · 👎,
  громкость, справа капсула из двух кнопок: скорость (часы) · эквалайзер (всплывашка по клику: пресеты и «+», кривая на 12 полос, «Сохранить» — одна кривая на все треки, без него правки не сохраняются; сделан в W4, переделан 2026-11-16). Мини-окно поверх всех окон — кнопкой справа от эквалайзера (решение владельца 2026-11-16, раньше «не делаем»): обложка, название, лайк, назад / пауза / вперёд, без перемотки. Ниже — **очередь**: контекст
  («Любимые» + перемешать), «Ранее» (последние сыгранные, клик — сыграть снова), «Сейчас играет», «Далее»
  со строками треков; при «вперёд / назад» строки переезжают между разделами.
- **Поиск** (`24`): вкладки Все / Треки / Артисты / Альбомы / Плейлисты (вкладку «По тексту» **не делаем**);
  «Лучший результат», «Треки» (❤ и длительность), «Артисты» (круглые, подписчики), «Альбомы».
- **Страница исполнителя** (`19`): большой аватар, @имя, слушатели и подписчики, кнопки
  Слушать · Подписаться · перемешать · в очередь · волна по артисту · 👎 · поделиться;
  «Популярные» (номер, обложка, прослушивания, ❤, длительность, ⋮), «Альбомы». Фон шапки и
  мини-плеер окрашены в цвет аватара/обложки.

### Мини-плеер: стили — это пресеты (`полный/гибрид/дек.png`, заметка владельца)

Выбор стиля сам выставляет остальные параметры (потом их можно поменять вручную):

| Стиль | Фон | Прогресс | Обложка | Форма |
|---|---|---|---|---|
| Отключено | — | — | — | — |
| Полный | тема | линия | по умолчанию | по умолчанию |
| Закруглённый | тема | вокруг обложки | круглая | капсула |
| Гибрид | тема | фоном | по умолчанию | по умолчанию |
| Дек | обложка | фоном | по умолчанию | по умолчанию |

«Закруглённый» — компактная капсула в левом нижнем углу над аватаром (`прогресс.png`).
В Sonar прогресс мини-плеера — **только линией и фоном** (решение владельца,
`прогресс.png`): «вокруг обложки» не делаем.

### Не переносим из Dotify
Друзья, Чаты, Комнаты, Слушатели (`прогресс.png`, правая часть), Подписка, баннер/статус/
«о себе» в профиле (`26`), почта и Google во «Входе» (`27`).

## Полноэкранный плеер на Windows (`reference/pc/fullscreen_player.webp`)

Открывается из мини-плеера, сверху по центру `⌄` — свернуть. Фон — размытая и затемнённая
обложка, по ней медленно плывёт и поворачивается одна огромная размытая её копия (как в Dotify: силуэт угадывается,
картинку не разобрать; при «меньше движения» стоят на месте). По центру колонкой:

1. **Обложка** — крупная, скругление 12–16 px. Поверх в нижних углах круглые
   полупрозрачные кнопки: слева **❤ лайк**, справа **👎 дизлайк** (дизлайк = сигнал своей
   волне и пропуск трека).
2. **Название** — крупно, жирным.
3. **Исполнитель** — с маленьким аватаром слева, приглушённым цветом; клик — страница артиста.
4. **Ползунок времени** — текущее время слева, длительность справа (стиль из `player.slider`).
5. **Кнопки:** повтор · назад · **пауза/плей** · вперёд · перемешать.
6. **Громкость** — тонкая полоска внизу экрана по центру, колесо мыши над ней тоже меняет.

**Текст песни:** если для трека нашёлся текст (SPEC §3.7б), он **сам показывается** в
полноэкранном режиме — колонка с обложкой и кнопками сдвигается влево, справа текст
(синхронный — караоке с автопрокруткой и подсветкой текущей строки, тап по строке — перемотка;
Genius — обычный текст с прокруткой). Текста нет — всё по центру, как на скрине. Кнопка «T»
позволяет скрыть/показать текст вручную. **Обновлено 2026-11-15 (как в Dotify):** кнопок «T» и ⋮
внизу нет — **правый клик в любом месте** открывает меню (**только если у трека есть текст**; нет текста — правый клик ничего не открывает): размер текста A A A A · вид (👁 обложка и
текст · только обложка · только текст — тогда сверху по центру плашка с обложкой, названием и
исполнителем, текст широкой колонкой) · Синхронизация, Стиль текста, Анимация (клик — следующее
значение) · Смещение ползунком ±2 с (колесо — по 10 мс, двойной клик по значению — сброс) ·
Перевести (после MVP) · Найти текст заново. Повтор — три разных значка: выключен (перечёркнут),
весь список, один трек. Таймлайн везде плывёт каждый кадр, без шага в секунду.

iOS-плеер устроен так же по составу (обложка → название → исполнитель → время → кнопки),
дизлайк там — в меню `⋮` и жестом.

## Анимации (решение владельца 2026-11-15: «всё должно быть анимировано»)

Общие правила для ПК, iOS, сайта и страницы статуса: длительность 140–450 мс, плавное замедление
(`--ease`, на iOS — spring), появляется — снизу/из масштаба 0.98 с прозрачностью, исчезает —
быстрее, чем появлялось. «Меньше движения» (`prefers-reduced-motion`, на iOS Reduce Motion) или
выключатель `appearance.animations` → только прозрачность.

| Что | Как | ПК сейчас |
|---|---|---|
| Смена страницы | проявление + сдвиг 6 px | ✅ |
| Открытие настроек | вкладки слева/справа: окно уезжает и наклоняется 15°, панель одновременно выезжает слева (как Dotify); вкладки сверху/снизу: шторка-пружина ~350 мс от панели вкладок, окно под вуалью с размытием | ✅ |
| Полноэкранный плеер | приближение + проявление, фон — плавающая обложка | ✅ |
| Меню трека, меню текста, эквалайзер, громкость | появление и **исчезание** | ✅ (`lib/motion.ts` `pop`) |
| Списки треков, плитки, карусели | каскадом, 20–30 мс между строками | ✅ (`use:cascade`) |
| Смена трека | обложка и название — кроссфейд, фон — плавно | ✅ |
| Лайк ❤ | «пульс» при нажатии | ✅ (`use:pulse`) |
| Плей / пауза | значок плавно сменяется | ✅ (`PlayPause`) |
| Вкладки (поиск, настройки, медиатека) | полоска-индикатор переезжает, содержимое — кроссфейд | ✅ (`use:indicator`) |
| Переключатели, кнопки | нажатие — масштаб 0.92–0.96 | ✅ |
| Строки текста | смена строки, подсветка слов, «•••» | ✅ |
| Тосты | выезжают и уезжают | ✅ |

## Синхронизация между ними

- Общие ключи (`SETTINGS.md`, sync = да) меняются на одном устройстве — приходят на другое.
- Платформенные ключи (жесты, масштаб, оверлей, устройство вывода) — только на своей.
- Лайки, плейлисты, очередь, текущий трек, скорость по трекам, свой фон — общие.
- «Продолжить на другом устройстве»: открыл Windows — там тот же трек и позиция, что были
  на телефоне (`GET /player/state`), если включено «Восстановление при запуске».

## Внешний вид

Один дизайн-язык: тёмная тема по умолчанию, матовое стекло, акцент под обложку,
скругления `pill`, те же иконки (Tabler/SF Symbols-аналоги), тот же логотип (`brand/`).

**Стиль (Интерфейс → Стиль, 2026-11-16) — одинаковый на Windows, iOS и Android.** Те же оси и
ключи (`SETTINGS.md` «Стиль»), те же готовые стили (Sonar, Эхо, Сигнал, Грань, Тактиль, Монолит) и
«Свой» с сохранением — стиль, собранный на ПК, приезжает на телефон синком. Цвет — OKLCH по формулам
поверхности (`windows/src/theme/palette.ts` `SURFACES` — числа те же для SwiftUI/Compose), шрифты —
те же семейства (на iOS из `ios/Sonar/Resources/Fonts`, wdth — переменными шрифтами), иконки панели —
те же SVG из частей с той же деталью у выбранной вкладки (таб-бар), анимации смены трека / лайка /
загрузки — те же описания и длительности (STYLE_PROMPT §4), «Уменьшение движения» — только
прозрачность. На телефоне «левая панель» — таб-бар, мини-плеер — тот же.
Компоненты называются одинаково в `ios/Sonar/DesignSystem` и `windows/ui` — проще переносить.
