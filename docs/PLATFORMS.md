# Sonar — iOS и Windows: что где

Правило: **одна структура на обеих платформах.** Те же разделы, те же названия, тот же
порядок, те же ключи настроек (`SETTINGS.md`). Отличается только то, чего физически нет на
другой платформе (жесты на телефоне, оверлей и трей на компьютере). Пользователь, который
знает одну версию, сразу находит всё в другой.

## Главные экраны

| Экран | iOS | Windows |
|---|---|---|
| Главная | Моя волна, Для вас, Открытия, Недавнее | то же, в 2–3 колонки |
| Медиатека | вкладки Все / Плейлисты / Альбомы / Исполнители, сетка 2 колонки | те же вкладки, сетка по ширине окна |
| Поиск | вкладка внизу | поле в шапке, `/` — фокус |
| Плейлист / Любимые | список, поиск, фильтр, перемешать | то же + колонки (альбом, дата добавления) |
| Плеер | полноэкранный, свайп вниз — закрыть | панель снизу + разворот на всё окно |
| Мини-плеер | капсула над таб-баром, сворачивается при прокрутке | полоса внизу окна, стили из `mini.*` |
| Очередь | лист из плеера | панель снизу / слева / справа (`queue.position`) |
| Текст песни | кнопка «T» в плеере | кнопка «T», панель справа |
| Скорость | кнопка «≡» → лист, «Запомнить» | то же меню |
| Профиль | вкладка внизу: шапка + меню настроек | аватар в шапке → окно настроек |
| Уведомления | колокольчик на главной | колокольчик в шапке |

## Полноэкранный плеер на Windows (`reference/pc/fullscreen_player.webp`)

Открывается из мини-плеера, сверху по центру `⌄` — свернуть. Фон — размытая и затемнённая
обложка (или цвет обложки, по настройке). По центру колонкой:

1. **Обложка** — крупная, скругление 12–16 px. Поверх в нижних углах круглые
   полупрозрачные кнопки: слева **❤ лайк**, справа **👎 дизлайк** (дизлайк = сигнал своей
   волне и пропуск трека).
2. **Название** — крупно, жирным.
3. **Исполнитель** — с маленьким аватаром слева, приглушённым цветом; клик — страница артиста.
4. **Ползунок времени** — текущее время слева, длительность справа (стиль из `player.slider`).
5. **Кнопки:** повтор · назад · **пауза/плей** · вперёд · перемешать.
6. **Громкость** — тонкая полоска внизу экрана по центру, колесо мыши над ней тоже меняет.

**Текст песни:** если для трека нашёлся текст (SPEC §3.7б), он **сам показывается** в
полноэкранном режиме — колонка с обложкой и кнопками сдвигается влево, справа текст
(синхронный — караоке с автопрокруткой и подсветкой текущей строки, тап по строке — перемотка;
Genius — обычный текст с прокруткой). Текста нет — всё по центру, как на скрине. Кнопка «T»
позволяет скрыть/показать текст вручную.

iOS-плеер устроен так же по составу (обложка → название → исполнитель → время → кнопки),
дизлайк там — в меню `⋮` и жестом.

## Настройки — одинаковые разделы

На Windows разделы — вкладки окна настроек (`reference/pc`), на iOS — группы в меню
профиля, **в том же порядке и с теми же названиями**:

| Раздел | Подразделы (оба) | Только iOS | Только Windows |
|---|---|---|---|
| **Аккаунт** | Профиль, Безопасность (пароль, Telegram, устройства), Статистика, Приватность 🔒 | — | — |
| **Интерфейс** | Вид (тема, под обложку, готовые темы, фон, стекло, скругление, шрифт, размер), Вкладки | стиль таб-бара, сворачивание | жирность шрифта, масштаб окна / на весь экран |
| **Плеер** | Аудио (качество, бесшовность, нормализация, уведомления/звонки), Вид (стиль, ползунок, кнопка, заголовок, аватары артистов), Очередь, Мини-плеер | **Жесты** | устройство вывода, кроссфейд, визуализатор, позиция обложки, **Оверлей** |
| **Сервисы** | SoundCloud (client_id + OAuth), Яндекс Музыка (в один клик / токен) | — | — |
| **Интеграции** | Last.fm, Ключ API («сейчас играет») | — | Discord RPC, OBS-плашка |
| **Система** | Общее (язык RU/EN, платформа SC/Яндекс, добавление в начало/конец, синхронизация), Хранилище (кэш треков, обложки, тексты, история поиска, настройки треков), Автообновление, О приложении (канал, сайт, версия), Сбросить, Выйти | — | автозапуск, трей, экономия ресурсов |

Горячих клавиш на Windows нет (решение владельца), кроме `/` для поиска.

## Синхронизация между ними

- Общие ключи (`SETTINGS.md`, sync = да) меняются на одном устройстве — приходят на другое.
- Платформенные ключи (жесты, масштаб, оверлей, устройство вывода) — только на своей.
- Лайки, плейлисты, очередь, текущий трек, скорость по трекам, свой фон — общие.
- «Продолжить на другом устройстве»: открыл Windows — там тот же трек и позиция, что были
  на телефоне (`GET /player/state`), если включено «Восстановление при запуске».

## Внешний вид

Один дизайн-язык: тёмная тема по умолчанию, матовое стекло, акцент под обложку,
скругления `pill`, те же иконки (Tabler/SF Symbols-аналоги), тот же логотип (`brand/`).
Компоненты называются одинаково в `ios/Sonar/DesignSystem` и `windows/ui` — проще переносить.
