# Sonar — план

Честная оценка: **сервер + iOS MVP ≈ 2–3 недели** плотной работы. Windows — отдельно,
ещё 2–3 недели. Ниже — порядок, в котором каждый шаг можно проверить руками.

Старт — **после покупки сервера (суббота)**, чтобы ничего не перестраивать. До этого —
только теория.

> делом вход + `/oauth/now` + ключ API для selfbot) → iOS. Этапы про сервер и iOS ниже
> остаются, но идут после блока W.

    релиз `windows-v<версия>` (установщик + `.sig`) и `latest.json` в `windows-latest`

    сборка NSIS проверена (6,8 МБ + `.sig`).
    **Шаг владельца (без него релиза не будет):** GitHub → Settings → Secrets and variables →
    Actions → New repository secret: `TAURI_SIGNING_PRIVATE_KEY` = всё содержимое файла
    `C:\Users\Folzy\.tauri\sonar-updater.key` (ключ сгенерирован 2026-11-15, без пароля; секрет
    `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` не нужен). Затем Actions → Windows → Run workflow — выйдет

    класть:** без него новые версии нельзя подписать, и у друзей обновления перестанут ставиться.
    Новая версия: поднять `version` в `tauri.conf.json`, `Cargo.toml`, `package.json` + запись в
    `updates/changelog.json` → пуш в `main`.

## Этап 1. Сервер: каркас (дни 1–3)

0. **Сначала проверка сервисов** (`server/tools/check_*.py`, токены владельца в `.env`):
   поток SC; доступ к Яндексу **с сервера Velt и с ПК владельца** (поиск, трек,
   download-info, похожие), с правильными заголовками и без спешки. По итогам — вариант из
   SPEC §3.7а и правка документов.
1. `server/` по `MAP.md`, `python -m sonar` поднимает FastAPI + бота.
2. БД и миграции по `DB.md`.
3. Регистрация, вход, сессии, устройства; **бот по `docs/BOT.md`**: `/start`, вход логином и
   паролем, регистрация, главное меню, профиль; быстрая ссылка `/auth/link` + окно подтверждения
   в Windows-клиенте. Баннеры бота (`server/tools/make_banners.py`) можно сделать до сервера.
4. Тесты на всё это. CI `server.yml`.
5. Деплой на Velt + туннель. **Проверка:** `curl <API>/health`.
6. `site/` на GitHub Pages: главная + страница профиля.
7. **Статус** (SPEC §3.11): проверки раз в 5 мин, `GET /status`, бот `/status`, страница
   `sonar.folzy.is-a.dev/status` (полоски за 90 дней, анимации), сообщения владельцу при сбое.
   Страницу можно сделать заранее, до сервера: без ответа API она честно покажет «недоступен».
