## 1. Что сделано в Windows-клиенте (W4 и сразу после)

- **Тексты:** Rust `windows/src-tauri/src/lyrics/` (lrclib → упрощённое название → «АРТИСТ - ТРЕК» →
  Genius → plain). Genius из Rust режет Cloudflare по TLS-отпечатку — запросы идут через системный
  `C:\Windows\System32\curl.exe`. Кэш в SQLite: **неделя с последнего прослушивания, у Любимых —
  две** (`used_at`, чистка при запуске). Ядро синхронизации — `windows/src/lyrics/core/` (тесты).
- **Полноэкранный плеер** (`windows/src/player/FullPlayer.svelte`): фон — одна огромная размытая
  копия обложки плывёт (как Dotify); **правый клик в любом месте** → меню как у Dotify
  (`windows/src/lyrics/LyricsMenu.svelte`): размеры A A A A, «глаза» — обложка+текст / только
  обложка / только текст (тогда сверху плашка с треком), Синхронизация / Стиль / Анимация (клик —
  следующее), Смещение ползунком ±2 с, Перевести (неактивна), Найти заново. **Без текста правый
  клик ничего не открывает.** Кнопок «T» и ⋮ внизу нет.
- **Мини-плеер:** фон = перемотка кликом/протяжкой, но без вида кнопки; **обложка открывает
  полноэкранный режим** (при наведении — две диагональные стрелки); таймлайн везде плывёт каждый
  кадр; повтор — три значка (выкл перечёркнут / всё / один).
- **Звук:** выбор качества 192 / 256 / 320 / «от 1411» (FLAC Яндекса через `get-file-info`);
  плашка реального формата в плеере. **SoundCloud без Go+ максимум AAC 160** — поэтому трек
  SoundCloud ищется на Яндексе (`providers/matching.rs`: артист, название ≥ 0.9, длительность ±3 с,
  одинаковые «версии») и играет оттуда (FLAC/320, плашка «FLAC · Яндекс»). Переключатель
  «SoundCloud в качестве Яндекса» в Настройки → Плеер → Аудио.
  Откуда у Dotify качество: свой сервер потоков (`C:/Users/Folzy/dotify-work/BACKEND.md`:
  `/track/{platform}/{id}`, `/track/.../change`, токены сервисов через `X-Platform-Token`).
  Их API подписан и закрыт — не используем, только идеи.
- **Эквалайзер** 12 полос (кнопка рядом со скоростью на странице плеера; мини-окна нет), пресеты,
  свои пресеты, «Запомнить» для трека (`track_prefs.eq_json`).
- **Настройки** — панель слева, окно уезжает вправо с наклоном 15°. Владелец: панель должна сама
  **выезжать слева направо** вместе с уходом окна (делает W5).
- **Боковые кнопки мыши** назад/вперёд; **иконка в векторе** (`brand/logo.svg`, `brand/icon/*.svg`).

## 2. Решения владельца (не переигрывать)

- **Всё анимировано** — «очень важно» (`docs/PLATFORMS.md` «Анимации»).
- Вид — один в один по `reference/pc` и Dotify, «не слопно»; всплывашки — только кликом.
- **Порядок:** W5 → W6 (0.1.0 друзьям) → сервер → iOS. Веб-плеер — **не сейчас** (звук и Яндекс в
  браузере упираются в сервер, который аудио не пропускает). Android — только если у кого-то из
  друзей появится (Tauri 2 умеет, сложность средняя: фоновое воспроизведение).
- Готовность Windows-клиента — ~55–60 % (с сервером ~50 %).
- **Сервер** Velt владелец купит **на неделе после 2026-11-15**.
- **Статус сервиса** — SPEC §3.11, API §9: страница `sonar.folzy.ru/status`, бот `/status`.
- **Бот** — `docs/BOT.md` (полная спека): только `/start` и `/status`; вход логин → пароль
  (сообщение с паролем удаляется) или **быстрая ссылка** (5 мин) с окном подтверждения в приложении
  (красное «Авторизация в аккаунт», «Разрешить» активна через 3 с); профиль: Рефералка ·
  Интеграция · Выйти (с подтверждением) · Версии; поддержка — **темы в группе-форуме** как в
  магазине владельца (`C:/Users/Folzy/Desktop/projects/TG store/project/services/support.py`),
  на каждое сообщение «✉️ Отправлено» / «📎 Прикреплено»; `/status`: Медиа и Прокси — только
  владельцу; **премиум-эмодзи по порядку** (таблица ID в одном месте, боты шлют их свободно).
- Почты нет. Google-вход — «в теории было бы прикольно», не в плане.
