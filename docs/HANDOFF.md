## 1. Что сделано (всё в `main`, CI `iOS` собирает и тестирует на симуляторе)

- **Релизы (этап 1):** `ios.yml` после тестов выкладывает `ios-build-<N>` с `Sonar.ipa` и обновляет служебный

  Actions → iOS → Run workflow с галкой `announce` вписывает собранную сборку сам (коммит от Folzy, `[skip ci]`).
- **Автообновление (этап 2), `ios/Sonar/Update/`:** порт ShadowSelfUpdate на async/await —
  UpdateManifest / UpdateChecker (при запуске и раз в 6 ч, всплывашка один раз на сборку, бейдж),
  SigningStore (+ Keychain), ProvisioningProfile, BundlePreparer, InstallServer (127.0.0.1, Range),
  InstallLinks (Semi Local через api.palera.in), InstallDiagnostics, SelfUpdater, InstallPage (Safari поверх

  версий**, всплывашка над таб-баром. `ios/Packages/Zsign` и `ios/Packages/ZipArchive` — из Shadow (MIT/zlib,
  LICENSE рядом), zsign без OpenSSL (Security.framework).
- **Найдено и исправлено в zsign:** в форке (Feather → Shadow) условие в `GenerateCodeResources` было
  перевёрнуто — `embedded.mobileprovision`, записанный при подписи, тут же удалялся, IPA уходила **без
  профиля**. В Sonar исправлено (`ios/Packages/Zsign/README.md`), тест проверяет профиль и его хэш в
  `CodeResources`. **В Shadow тот же баг** — если там обновление ставится, iOS брала профиль, уже
  установленный на телефоне; стоит перенести исправление и туда.
- **Ядро (этап 3), `ios/Sonar/Core/`:** модели как API.md, `JSONValue`, SoundCloud и Яндекс прямо с телефона
  (поиск, поток HLS / mp3 / FLAC, похожие, resolve, плейлисты, лайки, публичный client_id), ссылки, SC →
  Яндекс (Matching), `MusicCore` — порт `services.rs` (ключи в Keychain, кэш ссылок, повтор на свежем
  client_id). Тесты — те же случаи, что в Rust; подписи Яндекса сверены с эталоном.
- **Плеер и экраны (начало этапов 4–5):** `Playback/PlaybackEngine` (AVQueuePlayer, подгрузка за 15 с,
  свежая ссылка при ошибке, пропуск с сообщением, Now Playing и пульт, наушники/звонок, скорость с
  «Запомнить»), `Playback/Queue` (порт queue.ts с тестами); мини-плеер, полный плеер по `player.jpg`, лист

  (client_id / OAuth SoundCloud, Яндекс — вход по коду через `ya.ru/device` или токен).
- Проверка логики без Mac: Swift 6.1 для Linux (swift.org) + пакет-заглушка с символическими ссылками на
  Foundation-файлы — `swift test` гоняет те же XCTest-тесты (кроме UIKit / Network / Security). В репо не
  лежит; на CI всё гоняется по-настоящему.

## 2. Как проверить автообновление на телефоне (владелец)

1. Скачать `Sonar.ipa` по постоянной ссылке выше, поставить через ESign / Feather своей парой.
2. Sonar → Профиль → Система → Обновления → **Сертификат для подписи**: выбрать `.p12`, ввести пароль,
   выбрать `.mobileprovision` → должно быть «Пара подходит», профиль «подходит к установленному Sonar».
3. Сделать любой пуш в `ios/` (или Actions → iOS → Run workflow) с галкой **announce** — в
   `ios-update.json` появится новая сборка.
4. В Sonar: всплывашка «Доступно обновление» (или Обновления → «Проверить») → **Обновить** → загрузка →
   распаковка → подпись → упаковка → окно iOS «Установить?» → Sonar закрывается и обновляется. Любимые и
   настройки должны остаться. Не появилось окно за 10 с — под статусом причина и строка диагностики
   (прислать скрин), «Поделиться подписанной IPA» → поставить через ESign.
