# Чек-лист перед бетой — ПК и iPhone

Проверка руками: что пройти перед тем, как раздавать Sonar друзьям. Порядок — по шагам, сверху вниз:
следующий шаг часто опирается на предыдущий. Время — примерно.

**Как отмечать:** `[x]` — работает; `[!]` — сломано (рядом одна строка: что сделал → что ждал → что вышло);
`[-]` — не проверял (нет сервиса / нет второго монитора). Скрин или «Отправить лог» — к каждому `[!]`.

---

## Часть 1. Windows (~1,5–2 часа)

### Шаг 1. Чистая установка (10 мин)
- [ ] Скачать `Sonar-setup.exe` из последнего релиза (Releases → Latest).
- [ ] Запомнить, что пишет SmartScreen («неизвестный издатель» — ожидаемо, exe не подписан).
- [ ] Установщик: страница «Ярлыки» — галочки работают, ярлыки появились там, где выбрал.
- [ ] Первый запуск: заставка с лого, без пустой белой рамки.
- [ ] Второй запуск ярлыком — открывается то же окно, второго Sonar нет.
- [ ] Крестик — Sonar прячется в трей, музыка не прерывается; «Выход» в меню трея — закрывает.

### Шаг 2. Сервисы (15 мин)
Настройки → Сервисы. Каждый — подключить, найти трек, включить.
- [ ] SoundCloud — вход окном внутри Sonar (логин/пароль; если есть — через Google/Apple).
- [ ] Яндекс — «в один клик»: код, `ya.ru/device`, токен подхватился сам.
- [ ] YouTube Music — вход, трек играет.
- [ ] VK — вход, трек играет (если вылезла капча — записать `[!]`, это известная дыра).
- [ ] Spotify — вход; играет ли поток (может не играть — поток за отдельной фичей).
- [ ] Перезапустить Sonar — все входы сохранились.

### Шаг 3. Плеер (15 мин)
- [ ] Поиск: обычный и «Все» (единый) — результаты сверху из выбранного сервиса.
- [ ] Ctrl+K — открывает быстрый поиск, переход по результату.
- [ ] Играть, пауза, перемотка, громкость; медиа-клавиши клавиатуры; кнопки в превью на панели задач.
- [ ] Очередь: «Следующим», «В очередь», перетаскивание.
- [ ] Slowed / Sped up, эквалайзер (слышно разницу), качество FLAC у Яндекса.
- [ ] Трек недоступен в одном сервисе — играет замена из другого (резерв), в плашке видно откуда.
- [ ] Текст песни: синхронизируется, караоке, меню текста; трек без текста — понятная заглушка.
- [ ] Полноэкранный плеер, мини-окно поверх всех окон (по кнопке в плеере).

### Шаг 4. Медиатека (15 мин)
- [ ] Лайк — трек в «Любимых»; снять лайк — пропал.
- [ ] Свой плейлист: создать, добавить треки из разных сервисов, порядок, переименовать, удалить.
- [ ] Перенести плейлист SoundCloud / Яндекса в Sonar.
- [ ] Импорт по ссылке (плейлист Spotify / Apple Music / YouTube) — треки подобрались.
- [ ] Умный плейлист по правилам — наполнился.
- [ ] Дубли — нашлись, «объединить» и отмена (8 с).
- [ ] Экспорт плейлиста — файл открывается.
- [ ] Локальные файлы — папка с mp3/flac, играют.
- [ ] Страница исполнителя и альбома, меню трека (все пункты).

### Шаг 5. Волна, Главная, статистика (15 мин)
- [ ] Sonar Mix: каждое настроение хоть раз; 👎 — похожее больше не лезет.
- [ ] Главная: полки, стрелки полок, «Для тебя» → страница подборки.
- [ ] Карта исполнителей открывается, тянется, клик по исполнителю.
- [ ] Статистика после пары часов прослушивания — цифры похожи на правду; Итоги открываются.

### Шаг 6. Система (20 мин)
- [ ] Тема под обложку и готовые темы; Стиль — готовые и «Свой».
- [ ] Языки: русский, English, Українська — пройтись по экранам, найти непереведённое.
- [ ] Discord RPC — статус в профиле Discord.
- [ ] Автозапуск — после перезагрузки ПК Sonar в трее.
- [ ] Горячие клавиши (включить в Система → Горячие клавиши) — работают, когда Sonar не в фокусе.
- [ ] Оверлей: открыть, схема мониторов; с двумя мониторами — перетащить плашку (иначе `[-]`).
- [ ] Хранилище: размер кэша, очистка.
- [ ] Кнопки мыши назад/вперёд.

### Шаг 7. Обновление и сбой (10 мин)
- [ ] Система → Автообновление: проверка; когда выйдет новая версия — всплывашка «Доступно обновление»,
  обновилось, настройки и Любимые на месте.
- [ ] Журнал ошибок: если Sonar падал — плашка после запуска, «Отправить лог» доходит.

## Часть 2. iPhone (~1,5 часа)

### Шаг 1. Установка (15 мин)
- [ ] Скачать `Sonar.ipa` (релиз `ios-latest`), поставить через ESign своей парой.
- [ ] Запуск, иконка как у exe, ничего не вылетает.
- [ ] Система → Обновления → Сертификат: выбрать `.p12` (пароль) и `.mobileprovision` через «Файлы».

### Шаг 2. Самообновление — главное (15 мин)
Нужна сборка новее установленной (любой пуш в `main` с изменениями `ios/` её создаст).
- [ ] Всплывашка «Доступно обновление» → «Обновить».
- [ ] Загрузка → подпись → упаковка, Sonar не свёрнут.
- [ ] Страница установки: «Открыть» в окне «Открыть в iTunes?».
- [ ] Системное окно «Установить Sonar?» — «Установить».
- [ ] Только после этого — лист «выйди на рабочий стол»; выйти; иконка с кругом загрузки; новая версия
  открылась, Любимые на месте.
- [ ] Если застряло: скрин строки диагностики (`манифест palera … · репо … · Safari … · ipa …`).

### Шаг 3. Сервисы и плеер (20 мин)
- [ ] SoundCloud окном, Яндекс по коду — трек играет.
- [ ] Мини-плеер: перетекание панели в одну строку при прокрутке.
- [ ] Полный плеер: ⋮ — меню трека; тап по исполнителю — его страница; капсула сверху — очередь;
  свайп вниз — закрыть; свайп по обложке, двойной тап — лайк.
- [ ] Экран блокировки и Пункт управления: обложка, пауза, перемотка; наушники — пауза при отключении;
  звонок — пауза и продолжение.
- [ ] FLAC Яндекса играет; скорость с «Запомнить».
- [ ] Текст песни: караоке, меню (долгое нажатие), кнопки прячутся через 2,5 с.

### Шаг 4. Медиатека и Главная (15 мин)
- [ ] Любимые, свои плейлисты (создать, добавить, порядок, удалить), перенос плейлиста сервиса.
- [ ] Режим выбора в списке — перетаскивание.
- [ ] Скачать трек — играет без интернета (авиарежим).
- [ ] Главная: поле точек, «Для вас», Sonar Mix и «по треку».
- [ ] Свайп назад со страниц.

### Шаг 5. Виджет и Siri (10 мин)
- [ ] Виджет «Домой» (средний и маленький) — нажатие открывает Sonar и сразу играет.
- [ ] «Команды»: «Play My Wave in Sonar», пауза, дальше.

### Шаг 6. Пульт ПК ↔ iPhone (10 мин)
Одна Wi-Fi сеть; на ПК — Система → Пульт.
- [ ] iPhone нашёл ПК, привязка кодом.
- [ ] Пауза, следующий, громкость с телефона; обложка и время совпадают.

### Шаг 7. Мелочи (10 мин)
- [ ] Языки ru / en / uk — найти непереведённые экраны.
- [ ] Тема под обложку, «Меньше движения» в системе — без сдвигов.
- [ ] Сбой: плашка, «Отправить лог».

---

## Часть 3. Перед раздачей друзьям

- [ ] Все `[!]` из частей 1–2 — исправлены или записаны как «известное» для друзей.
- [ ] Короткая инструкция друзьям: где exe, что SmartScreen ругается — «Подробнее → Выполнить в любом случае»,
  как подключить сервисы, как прислать лог.
- [ ] iPhone — только тем, у кого есть своя пара `.p12` + `.mobileprovision` (или после того, как
  самообновление прошло у тебя до конца хотя бы раз).
- [ ] Договориться, куда слать баги (бот `@SonarMusicApp` → «Баг / Идея» или лично).
