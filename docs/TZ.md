# Sonar — техническое задание

Версия ТЗ: 1.0 · 2026-11-12 · мобильная версия (iOS) + сервер. Windows — отдельным этапом.

## 1. Что это

Свой плеер, «смесь SoundCloud и Яндекс Музыки». Замена Dotify, которой пользуется владелец:
та же идея (один клиент для нескольких сервисов), но свой код, свой сервер, своё API.

Пользователи: владелец и друзья (единицы человек). Регистрация открыта, но масштаб — до ~10.

## 2. Цели

1. Слушать SoundCloud и Яндекс Музыку в одном приложении, в одной очереди.
2. Свои лайки («Любимые») и смешанные плейлисты, общие для всех устройств.
3. «Моя волна» Яндекса прямо в Sonar.
4. Интерфейс подстраивается под цвет обложки играющего трека.
5. Статистика прослушиваний (неделя / месяц / год / всё время).
6. API «сейчас играет» для selfbot (формат Dotify) и скробблинг в Last.fm.
7. Автообновление приложения из GitHub Releases, как в Shadow.

## 4. Функциональные требования

### 4.1. Аккаунт

- **Регистрация:** шаг 1 — логин, шаг 2 — пароль. Логин: `a-z 0-9 _ .`, 3–32 символа, уникален,
  без учёта регистра. Логин **нельзя поменять** (только админ). `@username` при регистрации
  равен логину, потом меняется в профиле. Отображаемое имя — свободный текст.
- **Вход по паролю:** логин + пароль.
- **Быстрый вход через Telegram:** кнопка → на экране поле со ссылкой
  `https://t.me/<SonarBot>?start=login_<secret>`, кнопки «Скопировать», «Открыть», «Назад».
  Ссылку можно отдать другу: кто её откроет и подтвердит в боте, тот и войдёт **на этом
  устройстве**. Ссылка живёт 10 минут, одноразовая.
  - Telegram уже привязан к аккаунту → бот спрашивает «Войти в Sonar на <устройство>?» → вход.
  - Не привязан → бот предлагает создать аккаунт: логин = username Telegram (или `tg<id>`, если
    занят или его нет), пароль не задан (можно задать потом в «Безопасности»).
- **Привязка Telegram** к существующему аккаунту: «Безопасность» → «Привязать Telegram» →
  открывается бот `?start=link_<secret>` → привязано. Отвязать можно, только если задан пароль.
- **Устройства:** список сессий (модель, «Текущая сессия», последняя активность), выйти на любом.

### 4.2. Сервисы

- **SoundCloud:** поля `client_id` и `OAuth token` (подсказка, где их взять). Свой OAuth-вход
  SoundCloud не делаем: регистрация приложения требует платного Artist Pro.
- **Яндекс Музыка:** вход в один клик (OAuth Яндекса, страница в `ASWebAuthenticationSession`)
  или поле для токена `y0_...`.
- После подключения видны плейлисты и лайки сервиса — **фантомно** (не копируются). Пользователь
  выбирает плейлист → «Перенести в Sonar» → появляется плейлист Sonar с этими треками.
- Отключить сервис — токен удаляется с сервера.

### 4.3. Медиатека

- **Любимые** — свои лайки Sonar. Лайк в Sonar **не** ставит лайк в SC или Яндексе.
- **Плейлисты** — смешанные: треки SC и Яндекса вместе. Создать, переименовать, обложка
  (коллаж из 4 обложек по умолчанию), порядок, удалить, **скрыть** (долгое нажатие → «Скрыть»).
- Новые треки добавляются в начало или в конец (настройка).
- В списке трека: обложка, название, артист, длительность, иконка «скачан», меню `⋮`.

### 4.4. Воспроизведение

- Очередь из любых источников; «Следующим», «В очередь», удаление и перестановка.
- Бесшовное воспроизведение, нормализация громкости, поведение при уведомлениях/звонках
  (приглушить / пауза / ничего).
- Качество: Низкое / Среднее / Высокое / Максимальное. Берётся ближайшее, что даёт сервис
  (у SC — 128–256 кбит/с, у Яндекса — до FLAC).
- «Похожие треки»: когда очередь кончилась — догружать похожие (Яндекс: волна/похожие,
  SC: related).
- Восстановление при запуске: ничего / последний трек / вся очередь (с позицией).
- Экран блокировки, Пункт управления, Dynamic Island: обложка, название, кнопки, перемотка.
- Фоновое воспроизведение.

### 4.5. «Моя волна» и главная

- **Моя волна:** если подключён Яндекс — его rotor (`user:onyourwave`) с обратной связью
  (старт, пропуск, лайк, дослушал). Код волны Яндекса закрыт (это их сервер), но API открыт,
  и волна работает «как в Яндексе». Если Яндекса нет — волна из related SoundCloud по Любимым.
  Источник волны по умолчанию задаёт настройка «Предпочитаемая платформа».
- **Для вас / Открытия:** подборки сервиса (Яндекс: «Плейлист дня», «Премьера» и т.п.; SC: mixes
  и stations). Коллаж из 4 обложек + подпись с артистами.
- **Недавнее:** последние прослушанные треки и плейлисты.
- Приветствие по времени суток («Что включим этим утром?»).

### 4.6. Цвет под обложку

- Из обложки играющего трека берётся акцентный цвет. Им красятся кнопки, переключатели,
  ползунки, иконки, фон (если включено) — весь интерфейс, как на скринах (бирюзовый / оранжевый).
- Цвет плавно перетекает при смене трека (0,4 с). Контраст текста на акценте — не ниже 4.5:1.
- Выключено «Тема под обложку» → берётся выбранная готовая тема.

### 4.7. Жесты

Контексты: Медиатека (строка трека), Очередь, Мини-плеер, Плеер — свайп влево и вправо.
Тапы по обложке: двойной, тройной. Действия: Отключено, Лайк, Добавить в очередь, Следующим,
Следующий, Предыдущий, Удалить. Выбор — в нижнем листе (`photo_20`). Умолчания — в `SETTINGS.md`.

### 4.8. Статистика

Периоды: Неделя / Месяц / Год / Всё время. Переключатель Время / Треки.
- Итог периода (`39 ч 2 мин`) и % к прошлому периоду.
- Столбики по дням (неделя), по дням месяца, по месяцам (год).
- «Чаще всех» — артист и минуты. «Чаще всего» — плейлист/контекст и число треков.
- «Ещё любите» — топ-10 артистов по минутам.
- Кнопка «Поделиться» — картинка-карточка статистики.
- Блоки про друзей скрыты.
- Прослушивание засчитывается после 30 с или половины трека (правило Last.fm).

### 4.9. Синхронизация

- Лайки, плейлисты, настройки, очередь и текущий трек — на сервере, на всех устройствах.
- Автоматически: изменение уходит на сервер сразу; изменения с сервера подтягиваются при
  открытии приложения и раз в 60 с, пока оно открыто.
- Вручную («Основные» → «Синхронизация»): «Отправить на сервер» — локальное перезаписывает
  серверное, «Получить с сервера» — наоборот. С подтверждением.
- Офлайн: изменения копятся в очереди и уходят, когда есть сеть.

### 4.10. Интеграции

- **Last.fm:** подключить (веб-авторизация Last.fm), «История прослушиваний» (скроббл),
  «Сейчас играет». Скробблит **сервер**, поэтому работает с любого устройства.
- **API «сейчас играет»:** в «Интеграциях» — личный ключ (создать / перевыпустить / удалить).
  `GET https://sonar.folzy.ru/oauth/now` с `Authorization: Bearer <ключ>` отдаёт JSON в
  формате Dotify (см. `API.md` §7).

### 4.11. Кэш и скачивание

- «Скачать» трек или плейлист — файл хранится на устройстве, играет без сети.
- «Кэширование треков» — играющие треки сохраняются сами (лимит размера).
- Экран «Кэш»: занято всего, отдельно треки / обложки / тексты, «Очистить», история поиска.

### 4.12. Автообновление

- Приложение проверяет `updates/update.json` в репо (при запуске и раз в 6 ч).
- Есть новее → плашка «Доступно обновление 1.2.0» → экран с изменениями → «Скачать» →
  «Установить» → iOS ставит поверх (переподпись на устройстве сертификатом пользователя).
- Пользователь один раз кладёт свои `.p12` + пароль + `.mobileprovision` в «Автообновление».
- Если нет сертификата — кнопка «Скачать IPA» (поставить через ESign и т.п.).

## 5. Нефункциональные требования

- **iOS 17+**, iPhone. Тёмная тема по умолчанию. Матовое стекло (`.ultraThinMaterial` и свои
  настройки размытия/прозрачности), не Liquid Glass.
- Запуск до главной ≤ 1,5 с с кэшем. Старт трека ≤ 1 с на хорошей сети.
- Сервер: ≤ 150 МБ RAM, SQLite, ответ API ≤ 300 мс (без похода в сервисы).
- Токены сервисов на сервере — зашифрованы (Fernet), пароли — argon2id.
- Всё общение с сервером — HTTPS (`sonar.folzy.ru`).
- Языки: русский (основной), английский.

## 6. Ограничения и риски

| Риск | Что делаем |
|---|---|
| API SoundCloud и Яндекса неофициальные, могут сломаться | всё общение с сервисами — в двух модулях сервера; правка без обновления приложения |
| SoundCloud меняет `client_id` | пользователь вставляет свой; сервер умеет обновлять публичный (как `sc_api` в selfbot) |
| Нарушение правил сервисов | приложение не публикуется в App Store, для узкого круга |
| Ссылку быстрого входа могут подсунуть жертве (фишинг) | в боте — подтверждение с названием устройства и предупреждением; ссылка живёт 10 мин |
| Подпись истекает (сертификат пользователя) | автообновление переподписывает; напоминание за 7 дней |
| Мало RAM на хостинге | аудио через сервер не идёт; один процесс; SQLite |
| Нет Mac | сборка только в GitHub Actions; UI проверяется на устройстве после сборки |
