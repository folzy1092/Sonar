# Макет бота @SonarMusicApp

Живой макет экранов бота по `docs/BOT.md`: тёмная тема Telegram, баннеры, цитаты, inline-кнопки,
премиум-эмодзи из таблицы ID (`emoji/emoji.json`, картинки — первые кадры анимированных эмодзи).
Сервер не нужен — открой `index.html` в браузере (или `.claude/launch.json` → `bot-mockup`).

- Кнопки под сообщениями кликаются, навигация правит то же сообщение (как `edit_message_media`).
- Поле внизу: логин, пароль (`0000` — неверный), текст обращения, `/start`, `/status`; скрепка — «фото».
- Слева: быстрый переход к экранам, кто пишет (гость / Folzy / владелец — у владельца `/status` подробнее),
  состояние сервисов для `/status`, ответы поддержки (когда открыто обращение).
- «Быстрая ссылка» → «Открыть в Sonar» показывает окно подтверждения входа из приложения (кнопка «Разрешить» — через 3 с).
